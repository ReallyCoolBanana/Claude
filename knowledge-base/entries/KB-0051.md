## What Worked

### 1. Anti-Recursion Protocol (SOP-023)
The single most important factor. By enforcing 60-80% domain ratio and capping infrastructure at 1 agent per session, teams produced output instead of building tools. Session 1's 0% infrastructure constraint was the breakthrough moment.

### 2. Composite Scoring Formula
Fundamental (50%) + Sentiment (30%) + Macro (20%) provided a consistent, repeatable methodology. Applied identically across all 5 sessions. Produced picks with clear thesis documentation and risk parameters.

### 3. pick_logger.py
Created in Session 2, used in every subsequent session. Reduced pick creation from ~30 minutes (manual) to ~2 minutes (CLI). Auto-generated IDs, created properly formatted files, and updated the index automatically. Total picks created via pick_logger: 11 (of 16 total).

### 4. Parallel Agent Execution
Running research agents in parallel (2-3 at a time) while coordinator documented results maximized throughput within the 5-agent constraint. Every session used this pattern.

### 5. Sector Diversification Strategy
Starting with 3 sectors in Session 1 and adding 2-4 new sectors per session resulted in coverage across 13 sectors. No single sector has more than 2 picks, providing natural portfolio diversification.

## What Could Improve

### 1. All Positions Are Long
16 long positions with zero hedges in a VIX 25+ environment. Future sessions should add short positions, put protection, or inverse ETF positions.

### 2. Same-Day Performance Data Is Meaningless
All picks were created and reviewed on March 12, 2026. The Session 4 portfolio review showed +1.5% average, but this is noise — real performance data requires weeks of holding period.

### 3. No Technical Analysis
All 16 picks used fundamental analysis. The sentiment and technical methods documented in methods/ were not systematically applied. Future sessions should overlay chart analysis.

### 4. NVO FDA Risk Was Underweighted
NVO was included despite poor sentiment (4/10) because fundamentals were compelling. The FDA warning letter then materialized. Lesson: for pharma/biotech, regulatory risk should be weighted more heavily than fundamentals.

### 5. Source File Naming Mismatch
42 source files have naming inconsistency (descriptive suffixes not matching index references). This predates our sessions and was documented but not fixed.

## Recommendations for Sessions 6-10
1. **Add hedging capability.** At least one short/inverse position per session.
2. **Implement performance tracking.** Automated daily price checks against stops and targets.
3. **Apply technical analysis.** Overlay RSI, MACD, moving averages on existing picks.
4. **Build economic alert system.** FRED tool + scheduled checks for macro regime changes.
5. **Fix source naming.** Update source index to reference actual filenames.
6. **Consider closing NVO.** FDA response is imminent; thesis is the weakest in the portfolio.
7. **Raise RCL target.** Already hit $366 (above original $357 target) before pulling back.
8. **Maintain 60%+ domain ratio.** The anti-recursion protocol works — do not deviate.
