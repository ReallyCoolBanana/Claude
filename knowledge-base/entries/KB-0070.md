# pynvml (NVIDIA Management Library) for GPU Monitoring & VRAM Management

## Context
Research for building a local AI hub controller on an RTX 4070 Super that needs real-time
GPU monitoring, VRAM management, gaming detection, and integration with FastAPI and Prometheus.

## 1. Installation -- The Package Confusion

There are three packages on PyPI that all provide a `pynvml` Python module. Only one is correct:

| Package | Status | Notes |
|---------|--------|-------|
| **`nvidia-ml-py`** | **ACTIVE -- USE THIS** | Official NVIDIA bindings. Actively maintained. |
| `pynvml` | DEPRECATED | Emits `FutureWarning`. Folded back into `nvidia-ml-py`. |
| `nvidia-ml-py3` | OBSOLETE | Python 3 fork from 2017. Last release: v7.352.0. |

```bash
# CORRECT installation
pip install nvidia-ml-py

# If you have the deprecated packages, remove them first
pip uninstall pynvml nvidia-ml-py3 -y
pip install nvidia-ml-py
```

All three install the same `pynvml` module name, so conflicts are possible.
The import is always `from pynvml import *` regardless of which package is installed.

## 2. Getting VRAM Usage (Total, Used, Free)

```python
from pynvml import *

def get_vram_info(gpu_index: int = 0) -> dict:
    """Get VRAM usage in MB for a specific GPU."""
    nvmlInit()
    try:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)
        mem_info = nvmlDeviceGetMemoryInfo(handle)
        return {
            "total_mb": mem_info.total / (1024 ** 2),
            "used_mb": mem_info.used / (1024 ** 2),
            "free_mb": mem_info.free / (1024 ** 2),
            "used_percent": (mem_info.used / mem_info.total) * 100,
        }
    finally:
        nvmlShutdown()
```

RTX 4070 Super note: `mem_info.total` will report ~12288 MB (12 GB GDDR6X).

## 3. GPU Utilization Percentage

```python
from pynvml import *

def get_gpu_utilization(gpu_index: int = 0) -> dict:
    """Get GPU and memory controller utilization percentages."""
    nvmlInit()
    try:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)
        util = nvmlDeviceGetUtilizationRates(handle)

```

**Important**: `util.memory` is memory controller bandwidth utilization, NOT VRAM usage
percentage. For VRAM usage percentage, use `nvmlDeviceGetMemoryInfo` from section 2.

## 5. Per-Process VRAM Usage

```python
import psutil
from pynvml import *

def get_gpu_processes(gpu_index: int = 0) -> list[dict]:
    """Get per-process GPU memory usage.

    Returns both compute (CUDA) and graphics (OpenGL/DirectX/Vulkan) processes.
    """
    nvmlInit()
    try:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)
        processes = []

        # Compute processes (CUDA applications -- AI inference, training, etc.)
        try:
            compute_procs = nvmlDeviceGetComputeRunningProcesses(handle)
            for p in compute_procs:
                proc_name = "unknown"
                try:
                    proc_name = psutil.Process(p.pid).name()
                except (psutil.NoSuchProcess, psutil.AccessDenied):
                    pass
                processes.append({
                    "pid": p.pid,
                    "name": proc_name,
                    "type": "compute",
                    "vram_mb": (p.usedGpuMemory or 0) / (1024 ** 2),
                })
        except NVMLError:
            pass

        # Graphics processes (games, desktop compositors, video players)
        try:
            graphics_procs = nvmlDeviceGetGraphicsRunningProcesses(handle)
            for p in graphics_procs:
                proc_name = "unknown"
                try:
                    proc_name = psutil.Process(p.pid).name()
                except (psutil.NoSuchProcess, psutil.AccessDenied):
                    pass
                processes.append({
                    "pid": p.pid,
                    "name": proc_name,
                    "type": "graphics",
                    "vram_mb": (p.usedGpuMemory or 0) / (1024 ** 2),
                })
        except NVMLError:
            pass

        return processes
    finally:
        nvmlShutdown()
```

**Known bug (driver >= 500)**: `nvmlDeviceGetComputeRunningProcesses` may return processes
from ALL GPUs, not just the specified device index. Not an issue on single-GPU systems.

**Note**: `usedGpuMemory` can be `None` for some processes (especially graphics processes
on Windows). Always handle with `(p.usedGpuMemory or 0)`.

## 6. Power Draw and Clock Speeds

```python
from pynvml import *

def get_power_and_clocks(gpu_index: int = 0) -> dict:
    """Get power draw (watts) and clock speeds (MHz)."""
    nvmlInit()
    try:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)

        # Power usage -- returned in milliwatts, convert to watts
        power_mw = nvmlDeviceGetPowerUsage(handle)
        power_w = power_mw / 1000.0

        # Power limit
        power_limit_mw = nvmlDeviceGetPowerManagementLimit(handle)
        power_limit_w = power_limit_mw / 1000.0

        # Clock speeds in MHz
        graphics_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_GRAPHICS)
        mem_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_MEM)
        sm_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_SM)

        return {
            "power_draw_w": power_w,
            "power_limit_w": power_limit_w,
            "graphics_clock_mhz": graphics_clock,
            "memory_clock_mhz": mem_clock,
            "sm_clock_mhz": sm_clock,
        }
    finally:
        nvmlShutdown()
```

RTX 4070 Super: TDP ~220W, boost clock ~2475 MHz, memory clock ~1313 MHz (10504 effective).

## 7. Real-Time Monitoring Loop

```python
import time
import signal
from pynvml import *

def monitor_gpu(interval_seconds: float = 5.0, gpu_index: int = 0):
    """Continuous GPU monitoring loop. Ctrl+C to stop."""
    nvmlInit()
    handle = nvmlDeviceGetHandleByIndex(gpu_index)
    name = nvmlDeviceGetName(handle)
    if isinstance(name, bytes):
        name = name.decode("utf-8")

    print(f"Monitoring: {name} (index {gpu_index})")
    print(f"Sampling every {interval_seconds}s. Press Ctrl+C to stop.\n")
    print(f"{'Time':<10} {'GPU%':>5} {'VRAM MB':>10} {'VRAM%':>6} {'Temp':>5} {'Power':>7} {'GFX MHz':>8}")
    print("-" * 60)

    running = True
    def stop(sig, frame):
        nonlocal running
        running = False
    signal.signal(signal.SIGINT, stop)

    try:
        while running:
            util = nvmlDeviceGetUtilizationRates(handle)
            mem = nvmlDeviceGetMemoryInfo(handle)
            temp = nvmlDeviceGetTemperature(handle, NVML_TEMPERATURE_GPU)
            power = nvmlDeviceGetPowerUsage(handle) / 1000.0
            clk = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_GRAPHICS)

            ts = time.strftime("%H:%M:%S")
            vram_mb = mem.used / (1024 ** 2)
            vram_pct = (mem.used / mem.total) * 100

            print(f"{ts:<10} {util.gpu:>4}% {vram_mb:>9.0f} {vram_pct:>5.1f}% {temp:>4}C {power:>6.1f}W {clk:>7}")
            time.sleep(interval_seconds)
    finally:
        nvmlShutdown()

if __name__ == "__main__":
    monitor_gpu(interval_seconds=5.0)
```

**Key design choice**: Initialize NVML once, get the handle once, then reuse it in the loop.
Calling `nvmlInit()` / `nvmlShutdown()` every iteration adds unnecessary overhead.

## 8. FastAPI Integration -- /status Endpoint

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI
from pynvml import *
import threading

# Module-level NVML state
_nvml_lock = threading.Lock()
_nvml_initialized = False

@asynccontextmanager
async def lifespan(app: FastAPI):
    """Initialize NVML at startup, shutdown at exit."""
    global _nvml_initialized
    nvmlInit()
    _nvml_initialized = True
    yield
    nvmlShutdown()
    _nvml_initialized = False

app = FastAPI(lifespan=lifespan)

def _collect_gpu_stats(gpu_index: int = 0) -> dict:
    """Synchronous function to collect all GPU stats.

    Called from a threadpool by FastAPI when used with a sync endpoint,
    so we use a lock to protect NVML calls.
    """
    with _nvml_lock:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)
        name = nvmlDeviceGetName(handle)
        if isinstance(name, bytes):
            name = name.decode("utf-8")

        mem = nvmlDeviceGetMemoryInfo(handle)
        util = nvmlDeviceGetUtilizationRates(handle)
        temp = nvmlDeviceGetTemperature(handle, NVML_TEMPERATURE_GPU)
        power = nvmlDeviceGetPowerUsage(handle) / 1000.0
        power_limit = nvmlDeviceGetPowerManagementLimit(handle) / 1000.0
        gfx_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_GRAPHICS)
        mem_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_MEM)

        # Fan speed (may fail on some configs)
        try:
            fan_speed = nvmlDeviceGetFanSpeed(handle)
        except NVMLError:
            fan_speed = None

        # Per-process info
        processes = []
        try:
            for p in nvmlDeviceGetComputeRunningProcesses(handle):
                processes.append({
                    "pid": p.pid,
                    "type": "compute",
                    "vram_mb": (p.usedGpuMemory or 0) / (1024 ** 2),
                })
        except NVMLError:
            pass
        try:
            for p in nvmlDeviceGetGraphicsRunningProcesses(handle):
                processes.append({
                    "pid": p.pid,
                    "type": "graphics",
                    "vram_mb": (p.usedGpuMemory or 0) / (1024 ** 2),
                })
        except NVMLError:
            pass

        return {
            "gpu_name": name,
            "gpu_index": gpu_index,
            "driver_version": nvmlSystemGetDriverVersion(),
            "temperature_c": temp,
            "fan_speed_percent": fan_speed,
            "utilization": {
                "gpu_percent": util.gpu,
                "memory_controller_percent": util.memory,
            },
            "vram": {
                "total_mb": round(mem.total / (1024 ** 2)),
                "used_mb": round(mem.used / (1024 ** 2)),
                "free_mb": round(mem.free / (1024 ** 2)),
                "used_percent": round((mem.used / mem.total) * 100, 1),
            },
            "power": {
                "draw_w": round(power, 1),
                "limit_w": round(power_limit, 1),
            },
            "clocks": {
                "graphics_mhz": gfx_clock,
                "memory_mhz": mem_clock,
            },
            "processes": processes,
        }

@app.get("/status")
def gpu_status():
    """Full GPU status endpoint. FastAPI runs sync defs in a threadpool."""
    return _collect_gpu_stats(gpu_index=0)
```

## 9. Detecting Gaming Application Launch (Graceful AI Pause)

```python
import psutil
import time
from pynvml import *

# Known game executables (extend as needed)
KNOWN_GAME_PROCESSES = {
    "game.exe", "steam_game.exe", "javaw.exe",  # Minecraft
    "cs2.exe", "hl2.exe", "baldursgate3.exe",
    "cyberpunk2077.exe", "eldenring.exe",
    # Add your games here
}

# Thresholds for heuristic detection
GAMING_GPU_THRESHOLD = 50       # GPU util % that suggests active gaming
GAMING_VRAM_THRESHOLD_MB = 2000 # Graphics VRAM that suggests a game

def detect_gaming_activity(gpu_index: int = 0) -> dict:
    """Detect if a gaming application is actively using the GPU.

    Strategy:
      1. Check nvmlDeviceGetGraphicsRunningProcesses for known game executables
      2. If no known game found, use heuristic: high GPU util + high graphics VRAM
    """
    nvmlInit()
    try:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)
        util = nvmlDeviceGetUtilizationRates(handle)

        # Get graphics processes (games use OpenGL/DirectX/Vulkan)
        graphics_procs = []
        total_graphics_vram = 0.0
        try:
            for p in nvmlDeviceGetGraphicsRunningProcesses(handle):
                vram_mb = (p.usedGpuMemory or 0) / (1024 ** 2)
                total_graphics_vram += vram_mb
                try:
                    proc = psutil.Process(p.pid)
                    proc_name = proc.name().lower()
                    graphics_procs.append({
                        "pid": p.pid,
                        "name": proc_name,
                        "vram_mb": vram_mb,
                        "is_known_game": proc_name in KNOWN_GAME_PROCESSES,
                    })
                except (psutil.NoSuchProcess, psutil.AccessDenied):
                    pass
        except NVMLError:
            pass

        # Detection logic
        known_games = [p for p in graphics_procs if p["is_known_game"]]

        if known_games:
            return {
                "gaming_detected": True,
                "confidence": "high",
                "reason": f"Known game process: {known_games[0]['name']}",
                "game_processes": known_games,
                "gpu_util": util.gpu,
                "graphics_vram_mb": total_graphics_vram,
            }

        if (util.gpu > GAMING_GPU_THRESHOLD
                and total_graphics_vram > GAMING_VRAM_THRESHOLD_MB):
            return {
                "gaming_detected": True,
                "confidence": "medium",
                "reason": (f"High GPU util ({util.gpu}%) + high graphics VRAM "
                           f"({total_graphics_vram:.0f} MB)"),
                "game_processes": graphics_procs,
                "gpu_util": util.gpu,
                "graphics_vram_mb": total_graphics_vram,
            }

        return {
            "gaming_detected": False,
            "confidence": "high",
            "reason": "No gaming activity detected",
            "game_processes": [],
            "gpu_util": util.gpu,
            "graphics_vram_mb": total_graphics_vram,
        }
    finally:
        nvmlShutdown()


class GamingWatcher:
    """Background watcher that calls a callback when gaming starts/stops."""

    def __init__(self, on_gaming_start, on_gaming_stop,
                 poll_interval: float = 3.0, gpu_index: int = 0):
        self.on_gaming_start = on_gaming_start
        self.on_gaming_stop = on_gaming_stop
        self.poll_interval = poll_interval
        self.gpu_index = gpu_index
        self._gaming_active = False
        self._running = False

    def start(self):
        import threading
        self._running = True
        self._thread = threading.Thread(target=self._run, daemon=True)
        self._thread.start()

    def stop(self):
        self._running = False

    def _run(self):
        nvmlInit()
        try:
            while self._running:
                result = detect_gaming_activity(self.gpu_index)
                if result["gaming_detected"] and not self._gaming_active:
                    self._gaming_active = True
                    self.on_gaming_start(result)
                elif not result["gaming_detected"] and self._gaming_active:
                    self._gaming_active = False
                    self.on_gaming_stop(result)
                time.sleep(self.poll_interval)
        finally:
            nvmlShutdown()

# )
# watcher.start()
```

## 10. VRAM Threshold Alerts

```python
from pynvml import *
import logging

logger = logging.getLogger(__name__)

class VRAMMonitor:
    """Monitor VRAM and fire alerts when free memory drops below threshold."""

    def __init__(self, gpu_index: int = 0,
                 warning_threshold_mb: float = 2048,
                 critical_threshold_mb: float = 512):
        self.gpu_index = gpu_index
        self.warning_threshold_mb = warning_threshold_mb
        self.critical_threshold_mb = critical_threshold_mb
        self._last_alert_level = "ok"

    def check(self) -> dict:
        """Check VRAM and return alert status.

        Returns dict with keys: level ("ok"|"warning"|"critical"),
        free_mb, used_mb, total_mb, message
        """
        nvmlInit()
        try:
            handle = nvmlDeviceGetHandleByIndex(self.gpu_index)
            mem = nvmlDeviceGetMemoryInfo(handle)
            free_mb = mem.free / (1024 ** 2)
            used_mb = mem.used / (1024 ** 2)
            total_mb = mem.total / (1024 ** 2)

            if free_mb < self.critical_threshold_mb:
                level = "critical"
                msg = (f"CRITICAL: Only {free_mb:.0f} MB VRAM free "
                       f"(threshold: {self.critical_threshold_mb} MB)")
            elif free_mb < self.warning_threshold_mb:
                level = "warning"
                msg = (f"WARNING: {free_mb:.0f} MB VRAM free "
                       f"(threshold: {self.warning_threshold_mb} MB)")
            else:
                level = "ok"
                msg = f"OK: {free_mb:.0f} MB VRAM free"

            # Log only on state transitions
            if level != self._last_alert_level:
                if level == "critical":
                    logger.critical(msg)
                elif level == "warning":
                    logger.warning(msg)
                else:
                    logger.info(msg)
                self._last_alert_level = level

            return {
                "level": level,
                "free_mb": round(free_mb),
                "used_mb": round(used_mb),
                "total_mb": round(total_mb),
                "message": msg,
            }
        finally:
            nvmlShutdown()

# For the RTX 4070 Super (12 GB), reasonable thresholds:
# - warning at 2 GB free (10 GB used) -- consider pausing non-critical models
# - critical at 512 MB free (11.5 GB used) -- must shed load immediately
```

## 11. pynvml vs nvidia-smi Subprocess Calls

| Aspect | pynvml (nvidia-ml-py) | subprocess nvidia-smi |
|--------|----------------------|---------------------------------------|
| **Speed** | ~0.1-0.5ms per call | ~50-200ms per call (process spawn) |
| **Overhead** | Direct C library via ctypes | Fork+exec+parse stdout |
| **Reliability** | Exceptions on failure | Must parse text/CSV/XML output |
| **Structured data** | Native Python objects | Requires string parsing |
| **Thread safety** | Requires care (see section 13) | Each call is independent |
| **Dependency** | pip package + NVIDIA driver | nvidia-smi binary + driver |
| **Feature parity** | Full NVML API | Limited to nvidia-smi flags |

**Verdict**: pynvml is ~100-500x faster per query and returns structured data. Use it for
anything that polls more than once per minute. nvidia-smi is fine for one-off scripts or
when you cannot install pip packages.

```python
# Speed comparison
import time
import subprocess
from pynvml import *

# pynvml approach
nvmlInit()
handle = nvmlDeviceGetHandleByIndex(0)
start = time.perf_counter()
for _ in range(100):
    nvmlDeviceGetMemoryInfo(handle)
pynvml_time = (time.perf_counter() - start) / 100
nvmlShutdown()

# nvidia-smi approach
start = time.perf_counter()
for _ in range(10):  # only 10 iterations because it is slow
    subprocess.run(["nvidia-smi", "--query-gpu=memory.used",
                    "--format=csv,noheader"], capture_output=True)
smi_time = (time.perf_counter() - start) / 10

print(f"pynvml: {pynvml_time*1000:.2f} ms/call")
print(f"nvidia-smi: {smi_time*1000:.2f} ms/call")
print(f"Speedup: {smi_time/pynvml_time:.0f}x")
```

## 12. Known Issues on Consumer GPUs (GeForce RTX)

1. **ECC queries fail**: `nvmlDeviceGetEccMode()`, `nvmlDeviceGetMemoryErrorCounter()` etc.
   raise `NVML_ERROR_NOT_SUPPORTED` on GeForce cards. ECC is a datacenter/Quadro feature.

2. **Power management limit is read-only**: `nvmlDeviceSetPowerManagementLimit()`
   typically requires root and may not be supported on all consumer cards.
   `nvmlDeviceGetPowerManagementLimit()` (read) works fine.

3. **Fan speed by index**: `nvmlDeviceGetFanSpeed_v2(handle, fan_index)` may fail on
   some RTX cards. Fall back to `nvmlDeviceGetFanSpeed(handle)` which returns the
   overall/first fan speed.

4. **Graphics process VRAM can be None**: On Windows especially,
   `nvmlDeviceGetGraphicsRunningProcesses()` may return processes where
   `usedGpuMemory` is `None`.

5. **Driver version matters**: Some NVML functions require specific minimum driver versions.
   Keep drivers updated (550+ recommended for full RTX 40-series support).

6. **nvmlDeviceGetName returns bytes in older versions**: Some versions return `bytes`
   instead of `str`. Always handle: `name if isinstance(name, str) else name.decode()`.

7. **Persistence mode**: Consumer GPUs do not support `nvmlDeviceSetPersistenceMode()`.
   This is a datacenter feature.

8. **MIG (Multi-Instance GPU)**: Not available on consumer GPUs. MIG-related functions
   will raise `NVML_ERROR_NOT_SUPPORTED`.

## 13. Thread Safety

**NVML itself is thread-safe** at the C library level (the underlying `libnvidia-ml.so`
uses internal locking). However, the Python bindings add some caveats:

- **`nvmlInit()` and `nvmlShutdown()` are process-wide** -- call them once, not per-thread.
  Calling `nvmlShutdown()` while another thread is mid-query will cause errors.

- **Device handles are reusable across threads** -- once you have a handle from
  `nvmlDeviceGetHandleByIndex()`, it is safe to use from any thread.

- **For FastAPI specifically**:
  - `async def` endpoints run on the main event loop thread -- no thread concerns.
  - `def` (sync) endpoints run in FastAPI's threadpool -- multiple threads may call
    NVML simultaneously. This is safe because NVML is thread-safe, BUT you must ensure
    `nvmlInit()` has been called before any thread uses it, and `nvmlShutdown()` is not
    called until all threads are done.
  - **Recommended pattern**: Use the `lifespan` context manager to init/shutdown NVML,
    and a `threading.Lock` around NVML calls if you want to be extra cautious.

```python
# Safe pattern for multi-threaded access
import threading
from pynvml import *

_lock = threading.Lock()

def safe_get_gpu_stats():
    """Thread-safe GPU query. Lock prevents interleaved NVML calls."""
    with _lock:
        handle = nvmlDeviceGetHandleByIndex(0)
        mem = nvmlDeviceGetMemoryInfo(handle)
        util = nvmlDeviceGetUtilizationRates(handle)
        return {"vram_used": mem.used, "gpu_util": util.gpu}
```

For asyncio contexts, use `asyncio.to_thread()` to avoid blocking the event loop:

```python
import asyncio
from fastapi import FastAPI

app = FastAPI()

@app.get("/gpu")
async def get_gpu():
    stats = await asyncio.to_thread(safe_get_gpu_stats)
    return stats
```

## 14. Complete GPU Health Dashboard Endpoint

```python
"""
Complete GPU health dashboard for FastAPI.
Run: uvicorn gpu_dashboard:app --host 0.0.0.0 --port 8000
"""
import threading
import asyncio
from contextlib import asynccontextmanager
from datetime import datetime, timezone

import psutil
from fastapi import FastAPI
from pynvml import *

# ---- NVML lifecycle ----

_lock = threading.Lock()

@asynccontextmanager
async def lifespan(app: FastAPI):
    nvmlInit()
    yield
    nvmlShutdown()

app = FastAPI(title="GPU Health Dashboard", lifespan=lifespan)

# ---- Helpers ----

def _bytes_to_mb(b: int) -> float:
    return round(b / (1024 ** 2), 1)

def _safe_call(func, *args, default=None):
    """Call an NVML function, return default on NVML_ERROR_NOT_SUPPORTED."""
    try:
        return func(*args)
    except NVMLError:
        return default

def _get_process_info(procs, proc_type: str) -> list[dict]:
    results = []
    for p in procs:
        info = {"pid": p.pid, "type": proc_type,
                "vram_mb": _bytes_to_mb(p.usedGpuMemory or 0)}
        try:
            ps = psutil.Process(p.pid)
            info["name"] = ps.name()
            info["cmdline"] = " ".join(ps.cmdline()[:3])
        except (psutil.NoSuchProcess, psutil.AccessDenied):
            info["name"] = "unknown"
            info["cmdline"] = ""
        results.append(info)
    return results

# ---- Main collection function ----

def collect_full_stats(gpu_index: int = 0) -> dict:
    with _lock:
        handle = nvmlDeviceGetHandleByIndex(gpu_index)

        name = nvmlDeviceGetName(handle)
        if isinstance(name, bytes):
            name = name.decode("utf-8")

        driver = nvmlSystemGetDriverVersion()
        if isinstance(driver, bytes):
            driver = driver.decode("utf-8")

        mem = nvmlDeviceGetMemoryInfo(handle)
        util = nvmlDeviceGetUtilizationRates(handle)
        temp = nvmlDeviceGetTemperature(handle, NVML_TEMPERATURE_GPU)
        power = nvmlDeviceGetPowerUsage(handle) / 1000.0
        power_limit = _safe_call(nvmlDeviceGetPowerManagementLimit, handle, default=0) / 1000.0
        gfx_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_GRAPHICS)
        mem_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_MEM)
        sm_clock = nvmlDeviceGetClockInfo(handle, NVML_CLOCK_SM)
        fan = _safe_call(nvmlDeviceGetFanSpeed, handle, default=None)

        # Processes
        compute_procs = _safe_call(
            nvmlDeviceGetComputeRunningProcesses, handle, default=[])
        graphics_procs = _safe_call(
            nvmlDeviceGetGraphicsRunningProcesses, handle, default=[])

        processes = (
            _get_process_info(compute_procs or [], "compute") +
            _get_process_info(graphics_procs or [], "graphics")
        )

        # VRAM alert levels
        free_mb = mem.free / (1024 ** 2)
        if free_mb < 512:
            vram_alert = "critical"
        elif free_mb < 2048:
            vram_alert = "warning"
        else:
            vram_alert = "ok"

        return {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "gpu": {
                "name": name,
                "index": gpu_index,
                "driver_version": driver,
            },
            "temperature": {
                "gpu_c": temp,
                "throttle_c": 83,
            },
            "fan_speed_percent": fan,
            "utilization": {
                "gpu_percent": util.gpu,
                "memory_controller_percent": util.memory,
            },
            "vram": {
                "total_mb": _bytes_to_mb(mem.total),
                "used_mb": _bytes_to_mb(mem.used),
                "free_mb": _bytes_to_mb(mem.free),
                "used_percent": round((mem.used / mem.total) * 100, 1),
                "alert_level": vram_alert,
            },
            "power": {
                "draw_w": round(power, 1),
                "limit_w": round(power_limit, 1),
            },
            "clocks": {
                "graphics_mhz": gfx_clock,
                "memory_mhz": mem_clock,
                "sm_mhz": sm_clock,
            },
            "processes": processes,
            "process_summary": {
                "compute_count": len(compute_procs or []),
                "graphics_count": len(graphics_procs or []),
                "total_count": len(processes),
            },
        }

# ---- Endpoints ----

@app.get("/health")
```

```python
"""
GPU Prometheus metrics exporter.
Exposes metrics at /metrics for Prometheus scraping.

pip install nvidia-ml-py fastapi uvicorn prometheus-client
Run: uvicorn gpu_prometheus:app --host 0.0.0.0 --port 9400
"""
import threading
import asyncio
from contextlib import asynccontextmanager

from fastapi import FastAPI, Response
from prometheus_client import (
    Gauge, CollectorRegistry, generate_latest, CONTENT_TYPE_LATEST
)
from pynvml import *

# ---- Prometheus metrics ----

registry = CollectorRegistry()

GPU_TEMP = Gauge(
    "gpu_temperature_celsius", "GPU temperature", ["gpu_index"], registry=registry)
GPU_UTIL = Gauge(
    "gpu_utilization_percent", "GPU core utilization", ["gpu_index"], registry=registry)
GPU_MEM_UTIL = Gauge(
    "gpu_memory_controller_percent", "Memory controller utilization",
    ["gpu_index"], registry=registry)
VRAM_TOTAL = Gauge(
    "gpu_vram_total_bytes", "Total VRAM", ["gpu_index"], registry=registry)
VRAM_USED = Gauge(
    "gpu_vram_used_bytes", "Used VRAM", ["gpu_index"], registry=registry)
VRAM_FREE = Gauge(
    "gpu_vram_free_bytes", "Free VRAM", ["gpu_index"], registry=registry)
GPU_POWER = Gauge(
    "gpu_power_draw_watts", "GPU power draw", ["gpu_index"], registry=registry)
GPU_POWER_LIMIT = Gauge(
    "gpu_power_limit_watts", "GPU power limit", ["gpu_index"], registry=registry)
GPU_FAN = Gauge(
    "gpu_fan_speed_percent", "GPU fan speed", ["gpu_index"], registry=registry)
GPU_CLOCK_GFX = Gauge(
    "gpu_clock_graphics_mhz", "Graphics clock speed", ["gpu_index"], registry=registry)
GPU_CLOCK_MEM = Gauge(
    "gpu_clock_memory_mhz", "Memory clock speed", ["gpu_index"], registry=registry)
GPU_PROCESS_COUNT = Gauge(
    "gpu_process_count", "Number of GPU processes",
    ["gpu_index", "type"], registry=registry)

# ---- App ----

_lock = threading.Lock()

@asynccontextmanager
async def lifespan(app: FastAPI):
    nvmlInit()
    yield
    nvmlShutdown()

app = FastAPI(lifespan=lifespan)

def _update_metrics():
    """Collect GPU stats and update Prometheus gauges."""
    with _lock:
        device_count = nvmlDeviceGetCount()
        for i in range(device_count):
            idx = str(i)
            handle = nvmlDeviceGetHandleByIndex(i)

            temp = nvmlDeviceGetTemperature(handle, NVML_TEMPERATURE_GPU)
            GPU_TEMP.labels(gpu_index=idx).set(temp)

            util = nvmlDeviceGetUtilizationRates(handle)
            GPU_UTIL.labels(gpu_index=idx).set(util.gpu)
            GPU_MEM_UTIL.labels(gpu_index=idx).set(util.memory)

            mem = nvmlDeviceGetMemoryInfo(handle)
            VRAM_TOTAL.labels(gpu_index=idx).set(mem.total)
            VRAM_USED.labels(gpu_index=idx).set(mem.used)
            VRAM_FREE.labels(gpu_index=idx).set(mem.free)

            power = nvmlDeviceGetPowerUsage(handle) / 1000.0
            GPU_POWER.labels(gpu_index=idx).set(power)
            try:
                limit = nvmlDeviceGetPowerManagementLimit(handle) / 1000.0
                GPU_POWER_LIMIT.labels(gpu_index=idx).set(limit)
            except NVMLError:
                pass

            try:
                fan = nvmlDeviceGetFanSpeed(handle)
                GPU_FAN.labels(gpu_index=idx).set(fan)
            except NVMLError:
                pass

            GPU_CLOCK_GFX.labels(gpu_index=idx).set(
                nvmlDeviceGetClockInfo(handle, NVML_CLOCK_GRAPHICS))
            GPU_CLOCK_MEM.labels(gpu_index=idx).set(
                nvmlDeviceGetClockInfo(handle, NVML_CLOCK_MEM))

            try:
                compute = nvmlDeviceGetComputeRunningProcesses(handle)
                GPU_PROCESS_COUNT.labels(gpu_index=idx, type="compute").set(len(compute))
            except NVMLError:
                GPU_PROCESS_COUNT.labels(gpu_index=idx, type="compute").set(0)
            try:
                graphics = nvmlDeviceGetGraphicsRunningProcesses(handle)
                GPU_PROCESS_COUNT.labels(gpu_index=idx, type="graphics").set(len(graphics))
            except NVMLError:
                GPU_PROCESS_COUNT.labels(gpu_index=idx, type="graphics").set(0)

@app.get("/metrics")
async def metrics():
    """Prometheus scrape endpoint."""
    await asyncio.to_thread(_update_metrics)
    data = generate_latest(registry)
    return Response(content=data, media_type=CONTENT_TYPE_LATEST)

@app.get("/health")
async def health():
    return {"status": "ok"}
```

## Method
Researched official NVIDIA documentation, PyPI package status, community reports, and
NVML API reference. Cross-referenced with known consumer GPU limitations and FastAPI
concurrency model.

## Result
Comprehensive working reference for GPU monitoring via the official `nvidia-ml-py` package.
All code examples use the correct (non-deprecated) package and handle known edge cases
on consumer GeForce GPUs.

## Lessons Learned
1. The package naming is genuinely confusing -- three packages all install the pynvml module.
   Only nvidia-ml-py is correct going forward.
2. pynvml is pure Python ctypes -- no compilation needed, works everywhere the NVIDIA
   driver is installed.
3. ~100-500x faster than shelling out to nvidia-smi per query.
4. Consumer GPUs lack ECC, MIG, and persistence mode features -- wrap calls in try/except.
5. NVML is thread-safe at the C level, but nvmlInit/nvmlShutdown are process-wide --
   manage lifecycle carefully.
6. For gaming detection, use nvmlDeviceGetGraphicsRunningProcesses (not compute).
7. usedGpuMemory can be None on some processes -- always handle with (val or 0).

## Recommendations
- Install nvidia-ml-py, never pynvml or nvidia-ml-py3.
- Initialize NVML once at app startup, shut down at exit. Do not init/shutdown per-request.
- Use threading.Lock around NVML calls in FastAPI sync endpoints for extra safety.
- Use asyncio.to_thread() for async endpoints to avoid blocking the event loop.
- For gaming detection, combine nvmlDeviceGetGraphicsRunningProcesses with a known
  game executable list AND GPU utilization thresholds for best results.
- Keep NVIDIA drivers at 550+ for full RTX 40-series NVML support.
- For Prometheus, expose metrics at a separate port (e.g., 9400) and scrape every 15s.
