# cuGraph GPU Graph Analytics for Pointer Network (RTX 4070 Super)

## Context
Research on NVIDIA cuGraph (RAPIDS) for GPU-accelerated community detection, PageRank, and betweenness centrality on a knowledge graph with 50K-80K nodes and up to 1M edges on RTX 4070 Super (12GB VRAM).

## Installation
```bash
pip install nx-cugraph-cu12 --extra-index-url https://pypi.nvidia.com
# OR full cuGraph:
pip install cugraph-cu12 --extra-index-url https://pypi.nvidia.com
```
Requires Volta+ GPU (CC 7.0+), CUDA 12, Python 3.10-3.13, NetworkX >= 3.2.

## Zero-Code-Change GPU Acceleration (nx-cugraph)

Three methods to enable:

**Method 1 — Environment variable (recommended):**
```bash
NX_CUGRAPH_AUTOCONFIG=True python my_script.py
```

**Method 2 — Explicit backend:**
```python
nx.betweenness_centrality(G, backend="cugraph")
```

**Method 3 — Type-based:**
```python
import nx_cugraph as nxcg
nxcg_G = nxcg.from_networkx(G)
nx.pagerank(nxcg_G)  # auto-dispatches to GPU
```

Supports 60+ algorithms. Unsupported ones fall back to CPU transparently.

## Memory: Trivially Small
- 50K nodes / 1M edges: **~50-100 MB GPU memory** (~0.5-1% of 12 GB)
- Can coexist with FAISS GPU and sentence-transformers easily
- Run sequentially and call `torch.cuda.empty_cache()` between workloads

## Performance at 50K-80K Nodes

| Algorithm | CPU NetworkX | cuGraph | Speedup |
|-----------|-------------|---------|---------|
| PageRank | 1-5 sec | <0.1 sec | 10-100x |
| Louvain/Leiden | 5-30 sec | <1 sec | 10-315x |
| Betweenness (exact) | 10-60 min | seconds | **55-600x** |
| Betweenness (k=1000) | 1-5 min | <1 sec | **100x+** |

## Key Recommendations

1. **Use Leiden over Louvain** — Louvain can produce disconnected communities (up to 25% badly connected). Leiden guarantees well-connected communities.
2. **Use sampled betweenness centrality** (`k=1000-5000`) — this is where GPU pays off most
3. **nx-cugraph is the lowest-friction path** — one pip install + env var
4. **Not overkill at 50K nodes** — squarely in the "GPU beneficial" range, especially for iterative analysis

## API Examples

```python
import cugraph

# Community detection (Leiden)
parts, modularity = cugraph.leiden(G, resolution=1.0)

# PageRank
pr = cugraph.pagerank(G, alpha=0.85)

# Betweenness centrality (sampled)
bc = cugraph.betweenness_centrality(G, k=1000)
```
