# Free Public APIs for Developer Tools & General-Purpose Data

## Context
Needed to identify the best free public APIs for developer tools and general-purpose data that an AI system can use programmatically. Focus areas: code hosting (GitHub), package registries (npm, PyPI), IP/networking, and social/community data (Hacker News, Stack Exchange).

## Method
Systematic web search across each category, verifying base URLs, documentation links, authentication requirements, rate limits, and response formats. Live-tested each API endpoint. Created structured source files following the repository template.

## Result
Identified and cataloged 7 high-quality free public APIs:

1. **GitHub REST API** (SRC-0025) - Repos, code search, commits, issues, PRs, users, orgs, releases. Freemium (60/hr unauth, 5000/hr with free PAT).
2. **npm Registry API** (SRC-0026) - Package metadata, versions, download counts, dependency trees. Free, no auth required.
3. **PyPI JSON API** (SRC-0027) - Package metadata, versions, download URLs, vulnerability data, release history. Free, no auth required.
4. **ip-api.com Geolocation API** (SRC-0028) - IP geolocation, country, city, timezone, ISP data. Free for non-commercial use.
5. **Hacker News Algolia Search API** (SRC-0029) - Stories, comments, polls, users via full-text search. Free, no auth required.
6. **Hacker News Official API (Firebase)** (SRC-0030) - Real-time top/new/best stories, items, users. Free, no auth required.
7. **Stack Exchange API** (SRC-0031) - Questions, answers, comments, users, tags, badges, search. Freemium (300/day without key, 10,000/day with free registration).

## Lessons Learned
- Reddit API excluded: too restrictive for AI use (OAuth required, pre-approval process, increasing monetization pressure)
- Two Hacker News APIs serve complementary purposes: Firebase for real-time feeds, Algolia for search
- GitHub classified as freemium because unauthenticated 60/hr is too limited for practical use
- Stack Exchange 300/day without key is minimal; free registration for 10,000/day is the practical baseline
- Source IDs started at SRC-0025 since earlier teams already created SRC-0001 through SRC-0024

## Recommendations
- For code/repo data: GitHub API with a free PAT is essential
- For package ecosystem data: npm + PyPI together cover the two largest ecosystems
- For tech community insights: HN Algolia (search) + Firebase (trending) provide complete coverage
- For Q&A data: Stack Exchange API with free key registration
- Gaps remaining: GitLab API, crates.io (Rust), pkg.go.dev (Go), DNS lookup APIs, QR code generators, URL shorteners
