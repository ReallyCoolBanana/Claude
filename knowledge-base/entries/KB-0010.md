# Free Public APIs for AI/ML Self-Improvement

## Context
Researched publicly available APIs that an AI system could use to enhance its own capabilities in NLP, computer vision, embeddings, and commonsense reasoning. Focus was on free or freemium APIs with verified endpoints.

## Method
Systematic web search across 5 categories: NLP resources, image/CV APIs, ML model hubs, embedding APIs, and knowledge graphs. Each candidate was verified by fetching documentation and confirming endpoint URLs, auth methods, and rate limits.

## Result
Identified 6 high-quality APIs across the target categories:

### Tier 1: Completely Free (No Auth)
1. **Free Dictionary API** (SRC-0032) - Word definitions, phonetics, examples. No limits, no auth.
2. **Datamuse API** (SRC-0033) - Semantic word relationships, 100K requests/day, no auth.
3. **ConceptNet API** (SRC-0034) - Commonsense knowledge graph, 3600 req/hr, no auth.

### Tier 2: Freemium (API Key Required)
4. **Hugging Face Inference Providers** (SRC-0035) - Hundreds of ML models, free tier with monthly credits.
5. **Google Gemini Embeddings** (SRC-0036) - High-quality embeddings, 100 RPM free.
6. **Roboflow Inference** (SRC-0037) - Computer vision models, free tier + self-hosted option.

### AI Self-Improvement Value Rankings
- **Highest value**: ConceptNet (commonsense reasoning), Hugging Face (model access), Gemini Embeddings (semantic search)
- **High value**: Datamuse (word relationships), Roboflow (visual understanding)
- **Useful**: Free Dictionary (vocabulary augmentation)

## Lessons Learned
- The best free APIs for AI are those providing structured semantic data (ConceptNet, Datamuse) rather than just raw definitions.
- Embedding APIs (Gemini, HF) are critical for RAG and semantic search but freemium tiers have been shrinking (Google cut free quotas 50-80% in Dec 2025).
- Hugging Face's unified inference gateway is the single most versatile API, but rate limits are intentionally vague.
- ConceptNet is uniquely valuable: it provides commonsense knowledge that is difficult to obtain elsewhere.
- Self-hosted options (Roboflow Inference server, open-source embedding models) provide unlimited free usage but require infrastructure.

## Recommendations
- For immediate AI augmentation without any setup: start with ConceptNet and Datamuse (zero auth required).
- For embedding/RAG capabilities: Gemini Embeddings offers the best free tier quality, but consider self-hosted models (MiniLM-L6-v2, Nomic Embed Text V2) for no rate limits.
- For broad ML capability access: Hugging Face Inference Providers with a free token covers the widest range of tasks.
- Monitor Google's free tier changes -- they have been reducing quotas and may continue.
- Consider caching API responses locally to reduce rate limit pressure and improve response times.
