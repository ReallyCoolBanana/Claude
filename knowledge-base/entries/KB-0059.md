# Local AI Hub Controller — Filesystem Implementation for 1M Edges (RTX 4070 Super)

## Context
The pointer network and its supporting AI infrastructure (Claude sessions, knowledge base, coordination system) have been cloned to a home PC with an RTX 4070 Super (12GB VRAM). The local copy has grown to ~37,000 edges and the goal is 1,000,000-edge support. This entry adapts the full AI hub controller architecture from KB-0058 for **filesystem-based storage** at this scale — retaining the hub brain, sub-AIs, MCP integration, and GPU-accelerated intelligence layer.

This is NOT a simplified version. This is the same complex system designed for real deployment on a home PC.

## 1. Storage Layer: Filesystem at 1M Edges

### The Problem
A single `pointer-network.json` breaks at scale:

| Edges | File Size | Parse Time | Git Diff |
|-------|-----------|------------|----------|
| 37K | ~3.4 MB | 70ms | Usable |
| 100K | ~9.2 MB | 180ms | Ugly |
| 500K | ~45 MB | 900ms | Broken |
| 1M | ~92 MB | 1.8s | Broken |

### The Solution: Sharded Filesystem + Binary Cache

```
storage/pointer-network/
├── meta.json                          # Schema, global stats, shard manifest
├── nodes/
│   ├── KB/                            # One dir per domain
│   │   ├── KB-0001.json               # Node metadata + tags + summary
│   │   ├── KB-0002.json
│   │   └── ...
│   ├── TEAM/
│   ├── WIKI/                          # Wikipedia article nodes
│   ├── SRC/                           # Source nodes
│   └── SCR/                           # Script nodes
├── edges/
│   ├── by-source/
│   │   ├── KB-0001.edges.json         # All edges FROM KB-0001
│   │   └── ...
│   └── by-type/
│       ├── semantic_similarity.jsonl  # Append-only bulk edge logs
│       ├── predicted_links.jsonl
│       └── shared_tags.jsonl
├── embeddings/
│   ├── vectors.npy                    # All embeddings (N × 768 float32)
│   ├── id_map.json                    # Node ID ↔ vector index
│   └── faiss.index                    # GPU-loadable FAISS index
├── cache/
│   ├── adjacency.msgpack              # Full forward adjacency (binary)
│   ├── reverse-adj.msgpack            # Full reverse adjacency (binary)
│   └── node_index.msgpack             # Node metadata index for fast lookup
└── summaries/
    ├── KB-0001.summary.txt            # GPU-generated summaries
    └── ...
```

### Why Sharded Files + Binary Cache

- **Per-node reads**: Loading one node = one 1-5 KB file read (not 92 MB)
- **JSONL append**: New semantic edges = append one line. No rewrite.
- **msgpack cache**: Full adjacency loads in ~400ms at 1M edges (vs 1.8s JSON). Rebuilt after batch ops.
- **Git-friendly**: Only changed node/edge files appear in diffs
- **Domain directories**: Group nodes by type for easy filesystem navigation

### Cache Rebuild
After any batch edge operation, rebuild the binary adjacency cache:
```python
import msgpack, json, glob

adj, rev_adj = {}, {}
for f in glob.glob("storage/pointer-network/edges/by-source/*.edges.json"):
    nid = f.split("/")[-1].replace(".edges.json", "")
    edges = json.load(open(f))
    adj[nid] = [(e["to"], e["weight"], e.get("type","")) for e in edges]
    for e in edges:
        rev_adj.setdefault(e["to"], []).append((nid, e["weight"], e.get("type","")))

msgpack.pack(adj, open("cache/adjacency.msgpack","wb"))
msgpack.pack(rev_adj, open("cache/reverse-adj.msgpack","wb"))
```
At 1M edges this takes ~5 seconds. Once loaded, BFS/Dijkstra runs in single-digit ms.

The hub brain is the persistent orchestrator. It:
- Receives requests from Claude sessions via MCP
- Decomposes complex queries into sub-tasks
- Routes to the correct sub-AI worker
- Aggregates results and returns formatted responses
- Maintains awareness of what's loaded in VRAM

### Serving: llama.cpp Router Mode
llama.cpp's router mode (December 2025) is the foundation:
- Multi-process: each model runs isolated, crash-safe
- LRU eviction: auto-unloads least-recently-used models when VRAM is full
- On-demand loading: models only load when requested
- Per-model presets via `presets.ini`
- Hub brain set to `keep_alive: -1` (never unload)

```bash
llama-server \
  --models-dir ~/models/ \
  --port 8080 \
  --n-gpu-layers 999 \
  --ctx-size 8192
```

### Alternative: Ollama (simpler but buggier)
```bash
# Preload hub brain permanently
curl http://localhost:11434/api/generate -d '{"model":"phi4-mini:q5_k_m","keep_alive":-1}'
```
Ollama v0.7.0 has known VRAM leak issues. Prefer llama.cpp for production.

## 3. Sub-AI Workers

### VRAM Budget
```
Total VRAM:           12.0 GB
Hub Brain (always):    3.5 GB
Embedder (always):     0.5 GB
CUDA overhead:         0.5 GB
Available for workers: 7.5 GB
```

### Worker Registry

| Worker | Model / Engine | VRAM | Activation | Purpose |
|--------|---------------|------|------------|---------|
| **Embedder** | nomic-embed-text-v1.5 | 0.5 GB | Always-on | Text → 768-dim vectors |
| **Search** | FAISS GPU + cross-encoder reranker | 0.3-1.5 GB | On-demand | Semantic nearest neighbor |
| **Summarizer** | Phi-4 Mini (reuse hub) or Qwen3-4B | 0-4 GB | On-demand | Article/document summarization |
| **Graph AI** | PyKEEN (RotatE) + cuGraph | 1-2 GB | On-demand | Link prediction, community detection |
| **Classifier** | Fine-tuned DistilBERT | 0.3 GB | Always-on (CPU) | Fast intent routing (<5ms) |
| **Reranker** | cross-encoder/ms-marco-MiniLM-L-6 | 0.4 GB | On-demand | Precision filter after search |

### Concurrency Rules
- **Hub + Embedder + Classifier** always resident (4.3 GB on GPU, classifier on CPU)
- **One heavy worker at a time** (Summarizer OR Graph AI, not both)
- **Search + Reranker** can co-exist with hub (~5.7 GB total)
- **Summarizer trick**: Reuse the hub's Phi-4 Mini for summarization (no extra VRAM)

### VRAM Manager
Tracks loaded models via `pynvml` (Python NVIDIA Management Library):
```python
import pynvml
pynvml.nvmlInit()
handle = pynvml.nvmlDeviceGetHandleByIndex(0)
info = pynvml.nvmlDeviceGetMemoryInfo(handle)
free_mb = info.free / 1024**2
used_mb = info.used / 1024**2
```
Before loading a worker, check: `free_mb >= worker_vram_requirement`. If not, unload the LRU worker via llama.cpp API or Ollama `keep_alive: 0`.

## 4. Vector Search at This Scale

### Node Count vs Edge Count
At 1M edges, you'll have roughly **30K-80K nodes** (depending on edge density). This is a **trivially small** vector search problem for a GPU.

| Nodes | Embedding Size (768-dim) | FAISS Flat VRAM | Query Time |
|-------|-------------------------|-----------------|------------|
| 10K | 29 MB | 30 MB | <0.5ms |
| 50K | 146 MB | 150 MB | <1ms |
| 80K | 234 MB | 240 MB | <1ms |

**Use FAISS Flat (IndexFlatIP)** — exact inner product search, no approximation, no IVF-PQ overhead. At 80K vectors, flat search on GPU is sub-millisecond. You only need IVF-PQ when you exceed ~500K nodes.

### Embedding Pipeline
```python
from sentence_transformers import SentenceTransformer
import numpy as np, faiss, json, glob

model = SentenceTransformer("nomic-ai/nomic-embed-text-v1.5", device="cuda")

# Collect all node text
nodes, texts = [], []
for f in glob.glob("storage/pointer-network/nodes/**/*.json", recursive=True):
    node = json.load(open(f))
    nodes.append(node["id"])
    texts.append(f"search_document: {node.get('title','')} {' '.join(node.get('tags',[]))}")

# Batch embed
vectors = model.encode(texts, batch_size=256, normalize_embeddings=True, show_progress_bar=True)
np.save("storage/pointer-network/embeddings/vectors.npy", vectors)
json.dump(nodes, open("storage/pointer-network/embeddings/id_map.json","w"))

# Build FAISS index
index = faiss.IndexFlatIP(768)  # Inner product (cosine on normalized vectors)
index.add(vectors.astype(np.float32))
faiss.write_index(index, "storage/pointer-network/embeddings/faiss.index")
```

### Semantic Edge Generation
```python
# For each node, find top-k nearest neighbors → create semantic edges
for i, node_id in enumerate(nodes):
    D, I = index.search(vectors[i:i+1], 20)
    for score, j in zip(D[0], I[0]):
        if j == i or score < 0.7:
            continue
        target_id = nodes[j]
        # Append to edge file and JSONL log
        edge = {"to": target_id, "weight": int(score * 10), "type": "semantic_similarity",
                "reasons": [f"cosine:{score:.3f}"], "strength": weight_to_strength(int(score*10))}
        ...
```

Expected yield: 50K nodes × ~5 new semantic edges = **~250K new edges** in one batch.

## 5. FastAPI Hub Service

The central service running on your PC. All Claude sessions connect through this.

```python
# hub_service.py
from fastapi import FastAPI
from contextlib import asynccontextmanager
import faiss, numpy as np, json, msgpack
from sentence_transformers import SentenceTransformer

@asynccontextmanager
async def lifespan(app):
    # Load at startup
    app.state.model = SentenceTransformer("nomic-ai/nomic-embed-text-v1.5", device="cuda")
    app.state.index = faiss.read_index("storage/pointer-network/embeddings/faiss.index")
    app.state.id_map = json.load(open("storage/pointer-network/embeddings/id_map.json"))
    app.state.adj = msgpack.unpack(open("storage/pointer-network/cache/adjacency.msgpack","rb"), raw=False)
    app.state.rev_adj = msgpack.unpack(open("storage/pointer-network/cache/reverse-adj.msgpack","rb"), raw=False)
    yield

app = FastAPI(lifespan=lifespan)

@app.post("/search")
async def semantic_search(query: str, k: int = 10):
    vec = app.state.model.encode([f"search_query: {query}"], normalize_embeddings=True)
    D, I = app.state.index.search(vec.astype(np.float32), k)
    return [{"id": app.state.id_map[i], "score": float(d)} for d, i in zip(D[0], I[0]) if i >= 0]

@app.post("/embed")
async def embed_text(texts: list[str]):
    vecs = app.state.model.encode(texts, normalize_embeddings=True)
    return {"vectors": vecs.tolist()}

@app.post("/traverse")
async def graph_traverse(start: str, max_hops: int = 3, min_weight: int = 3):
    """BFS traversal from a node, returning connected subgraph."""
    visited, queue, result = set(), [(start, 0)], []
    while queue:
        node, depth = queue.pop(0)
        if node in visited or depth > max_hops:
            continue
        visited.add(node)
        edges = app.state.adj.get(node, [])
        neighbors = [(t, w, tp) for t, w, tp in edges if w >= min_weight and t not in visited]
        result.append({"node": node, "depth": depth, "edges": neighbors})
        queue.extend([(t, depth+1) for t, w, tp in neighbors])
    return result

@app.post("/add-node")
async def add_node(node_id: str, domain: str, text: str, tags: list[str]):
    """Embed a new node, add to index, find semantic neighbors, create edges."""
    vec = app.state.model.encode([f"search_document: {text} {' '.join(tags)}"], normalize_embeddings=True)

    # Find neighbors
    D, I = app.state.index.search(vec.astype(np.float32), 20)
    new_edges = []
    for score, j in zip(D[0], I[0]):
        if score < 0.7 or j < 0:
            continue
        target = app.state.id_map[j]
        new_edges.append({"to": target, "weight": int(score*10),
                         "type": "semantic_similarity", "reasons": [f"cosine:{score:.3f}"]})

    # Write node file, edge file, update index
    # ... (filesystem writes)

    return {"node_id": node_id, "edges_created": len(new_edges), "neighbors": new_edges[:5]}

@app.get("/status")
async def hub_status():
    import pynvml
    pynvml.nvmlInit()
    handle = pynvml.nvmlDeviceGetHandleByIndex(0)
    mem = pynvml.nvmlDeviceGetMemoryInfo(handle)
    return {
        "nodes": len(app.state.id_map),
        "edges": sum(len(v) for v in app.state.adj.values()),
        "vram_used_gb": round(mem.used / 1024**3, 2),
        "vram_free_gb": round(mem.free / 1024**3, 2),
        "index_size": app.state.index.ntotal,
    }

@app.post("/predict-links")
async def predict_links(node_id: str, k: int = 10):
    """Use semantic similarity to predict missing edges for a node."""
    idx = app.state.id_map.index(node_id)
    vectors = np.load("storage/pointer-network/embeddings/vectors.npy")
    vec = vectors[idx:idx+1]
    D, I = app.state.index.search(vec, k + 20)
    existing = set(t for t, w, tp in app.state.adj.get(node_id, []))
    predictions = []
    for score, j in zip(D[0], I[0]):
        target = app.state.id_map[j]
        if target == node_id or target in existing:
            continue
        predictions.append({"target": target, "confidence": float(score)})
        if len(predictions) >= k:
            break
    return predictions

@app.post("/summarize")
async def summarize(text: str, max_length: int = 300):
    """Route to hub brain (Phi-4 Mini) for summarization."""
    import httpx
    async with httpx.AsyncClient() as client:
        resp = await client.post("http://localhost:8080/v1/chat/completions", json={
            "model": "phi-4-mini",
            "messages": [
                {"role": "system", "content": "Summarize the following text concisely. Extract key concepts and relationships."},
                {"role": "user", "content": text[:4000]}
            ],
            "max_tokens": max_length
        })
    return resp.json()["choices"][0]["message"]["content"]

@app.post("/community-detect")
async def detect_communities(min_community_size: int = 5):
    """Run Louvain community detection on the adjacency graph."""
    import networkx as nx
    from networkx.algorithms.community import louvain_communities

    G = nx.DiGraph()
    for src, edges in app.state.adj.items():
        for target, weight, etype in edges:
            G.add_edge(src, target, weight=weight)

    communities = louvain_communities(G.to_undirected(), weight="weight", resolution=1.0)
    return [{"community_id": i, "size": len(c), "members": list(c)[:20]}
            for i, c in enumerate(sorted(communities, key=len, reverse=True))
            if len(c) >= min_community_size]
```

Run with: `uvicorn hub_service:app --host 0.0.0.0 --port 8000`

## 7. Hub Brain: Task Decomposition and Routing

The Phi-4 Mini hub brain doesn't just summarize — it's the intelligent dispatcher. When a Claude session asks a complex question, the hub decomposes it:

### Example Flow
```
Claude: "Find all knowledge base entries related to neural networks
         and predict what new connections should exist"

Hub Brain decomposes:
  1. gpu_search("neural networks", k=20)     → Search worker
  2. gpu_traverse(result[0].id, max_hops=2)  → Adjacency cache
  3. gpu_predict_links(result[0].id, k=10)   → Graph AI worker
  4. Aggregate and format results             → Hub brain

Returns to Claude:
  - 20 semantically related nodes
  - 2-hop subgraph around the top result
  - 10 predicted missing edges with confidence scores
```

### Hub Brain System Prompt
```
You are the local AI hub controller. You receive requests from Claude sessions
and decompose them into calls to your available tools:
- search: semantic vector search across the pointer network
- traverse: BFS graph traversal from a node
- predict_links: find missing connections
- summarize: condense text
- embed: generate embeddings
- community_detect: find topic clusters

Decompose complex requests into the minimal set of tool calls needed.
Return structured JSON results. Be concise.
```

### When the Hub Brain Adds Value vs Direct Tool Calls
- **Simple queries** (search, traverse): Claude calls MCP tools directly, no hub brain needed
- **Complex queries** (multi-step analysis, cross-referencing): Hub brain decomposes into pipeline
- **Batch operations** (embed 1000 new articles): Hub brain manages queue and progress
- **Maintenance** (retrain index, rebuild cache): Hub brain coordinates the sequence

## 9. Link Prediction with PyKEEN

For going beyond semantic similarity to structural edge prediction:

```python
# Convert pointer network to PyKEEN triples
import json, glob, numpy as np
from pykeen.triples import TriplesFactory
from pykeen.pipeline import pipeline

triples = []
for f in glob.glob("storage/pointer-network/edges/by-source/*.edges.json"):
    source = f.split("/")[-1].replace(".edges.json", "")
    for edge in json.load(open(f)):
        triples.append([source, edge.get("type", "related"), edge["to"]])

tf = TriplesFactory.from_labeled_triples(np.array(triples))
train, test = tf.split([0.9, 0.1])

result = pipeline(
    training=train, testing=test,
    model="RotatE",
    model_kwargs=dict(embedding_dim=128),
    training_kwargs=dict(num_epochs=200, batch_size=512),
    device="cuda"
)

# Predict missing edges
from pykeen.predict import predict_target
predictions = predict_target(result.model, head="KB-0001", relation="semantic_similarity", triples_factory=tf)
```

VRAM: < 1 GB for a 50K-80K node graph. Runs alongside hub brain easily.

## Recommendations

1. **Keep the full AI hub architecture** — hub brain + sub-AIs + MCP. The intelligence layer is what makes this more than a database.
2. **Shard the JSON first** — this unblocks everything else
3. **Phi-4 Mini as hub brain** — 3.5 GB leaves plenty of room. Reuse it for summarization.
4. **FAISS Flat, not IVF-PQ** — your node count is small enough for exact search
5. **nomic-embed-text-v1.5** — best quality at 768-dim for this VRAM budget
6. **llama.cpp router mode** over Ollama — more reliable VRAM management
7. **Background daemon** keeps the network self-updating
