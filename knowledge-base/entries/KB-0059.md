# PNAM v3: Hierarchical Sub-Networks with Exponential Depth Penalty

## Context

The pointer network is evolving from a flat graph into a **two-layer hierarchical structure**:

```
┌──────────────────────────────────────────────────────────────────┐
│                        MAIN LAYER                                │
│   ┌─────┐     ┌─────┐     ┌─────┐     ┌─────┐     ┌─────┐     │
│   │Wiki │────▶│Wiki │────▶│ RFC │────▶│Paper│────▶│ KB  │     │
│   │Art.A│     │Art.B│     │ 793 │     │ X   │     │Entry│     │
│   └──┬──┘     └──┬──┘     └──┬──┘     └──┬──┘     └─────┘     │
│      │            │            │            │                     │
│ ─────┼────────────┼────────────┼────────────┼──── layer boundary │
│      ▼            ▼            ▼            ▼                     │
│   ┌──────┐    ┌──────┐    ┌──────┐    ┌──────┐                  │
│   │Subnet│    │Subnet│    │Subnet│    │Subnet│                  │
│   │  A   │    │  B   │    │  C   │    │  D   │                  │
│   │      │    │      │    │      │    │      │                  │
│   │[c1]──┼───▶│[c4]  │    │[§3]──┼───▶│[ref2]│  cross-subnet   │
│   │[c2]  │    │[c5]──┼───▶│[§4]  │    │[ref3]│  links          │
│   │[c3]──┼────┼──────┼───▶│[§5]  │    │[ref4]│                  │
│   └──────┘    └──────┘    └──────┘    └──────┘                  │
│                                                                  │
│   c=citation  §=section  ref=reference                          │
└──────────────────────────────────────────────────────────────────┘

Movement rules:
  Main→Main:   normal cost (weight-based, as today)
  Main→Subnet: "dive" — free (entering a node's details)
  Subnet→Subnet (same parent): exponential depth penalty
  Subnet→Subnet (cross-link): jump cost + depth penalty
  Subnet→Main: "surface" — free (returning to main layer)
```

## Method: Hierarchical PNAM

### Key Architectural Changes from v2

| Component | v2 (KB-0057) | v3 (This Entry) |
|-----------|-------------|------------------|
| Graph structure | Flat, single layer | **Two-layer: main + subnets** |
| Edge types | 5 types (shared_tags, etc.) | **+ dive, surface, internal, cross-subnet** |
| Cost model | Weight-based (1-10) | **Weight + exponential depth penalty** |
| GNN | Homogeneous GraphSAGE | **Heterogeneous GNN (HeteroSAGE)** |
| Pathfinder | Single-layer next-hop | **Hierarchical: decide dive/surface/traverse** |
| Node features | Fixed per node | **+ layer position, depth, parent ID** |
| Training | Edge-level batches | **+ hierarchical traversal sequences** |

### The Exponential Depth Penalty

When an agent enters a subnet and traverses within it, each additional hop costs
exponentially more. This creates a natural pressure to "surface" back to the main
layer rather than wandering deep into citation chains.

```python
class HierarchicalCostModel:
    """
    Cost model for the two-layer network.

    Main layer traversal: normal weight-based cost
    Subnet traversal: exponential penalty based on depth from entry point
    Dive/surface transitions: configurable fixed cost (default: free)
    """
    def __init__(self, base=2.0, dive_cost=0.0, surface_cost=0.0,
                 cross_subnet_base_cost=3.0):
        self.base = base                          # exponential base
        self.dive_cost = dive_cost                # main → subnet
        self.surface_cost = surface_cost          # subnet → main
        self.cross_subnet_base_cost = cross_subnet_base_cost

    def edge_cost(self, edge, current_depth=0):
        """
        Calculate the cost of traversing an edge.

        Args:
            edge: dict with 'type', 'weight', 'layer' info
            current_depth: how many hops deep we are in the current subnet
        """
        if edge['type'] == 'main_to_main':
            # Normal main-layer traversal
            return 10 - edge['weight']  # invert: high weight = low cost

        elif edge['type'] == 'dive':
            # Entering a subnet (main → subnet)
            return self.dive_cost  # free by default

        elif edge['type'] == 'surface':
            # Returning to main layer (subnet → main)
            return self.surface_cost  # free by default

        elif edge['type'] == 'internal':
            # Moving within a subnet
            new_depth = current_depth + 1
            base_cost = 10 - edge.get('weight', 5)
            penalty = self.base ** new_depth  # EXPONENTIAL
            return base_cost * penalty

        elif edge['type'] == 'cross_subnet':
            # Jumping between subnets (subnet A → subnet B)
            # Cost = base jump cost + exponential penalty at new depth
            new_depth = current_depth + 1
            penalty = self.base ** new_depth
            return self.cross_subnet_base_cost * penalty

    def path_cost(self, path):
        """Total cost of a multi-hop path through the hierarchical network."""
        total = 0.0
        depth = 0
        for edge in path:
            cost = self.edge_cost(edge, depth)
            total += cost

            # Track depth
            if edge['type'] == 'dive':
                depth = 0  # reset depth on new subnet entry
            elif edge['type'] == 'surface':
                depth = 0  # reset depth on return to main
            elif edge['type'] in ('internal', 'cross_subnet'):
                depth += 1
            # main_to_main doesn't change depth

        return total
```

**Why exponential and not linear**: The key insight is that citation chains have
diminishing relevance. If article A cites paper B, which cites paper C, which cites
paper D — the relevance of D to A drops off exponentially, not linearly. A linear
penalty would let the agent wander 10 hops deep for only 10x cost. Exponential (base 2)
means 10 hops deep = 1024x cost, which makes it almost always cheaper to surface and
find a better main-layer route.

**The sweet spot**: At base=2, the breakeven is roughly:
- 1-2 subnet hops: usually worth it (2-4x cost, often finds useful cross-links)
- 3 hops: sometimes worth it for high-weight paths (8x cost)
- 4+ hops: almost never worth it (16x+ cost) — surface and traverse main layer instead

This matches the intuition: look at an article's citations (1 hop), maybe check what
those citations cite (2 hops), but don't go deeper — surface and travel the main network.

### Storage Architecture

Subnets should NOT live inside `pointer-network.json` — that file would become
enormous. Instead, use a sharded storage model:

```
storage/
├── pointer-network.json              # Main layer only (~5K-50K nodes)
├── subnets/
│   ├── index.json                    # Subnet metadata + entry points
│   ├── wikipedia/
│   │   ├── transformer.subnet.json   # One file per parent node
│   │   ├── attention.subnet.json
│   │   └── ...
│   ├── rfcs/
│   │   ├── rfc793.subnet.json
│   │   └── ...
│   ├── papers/
│   │   ├── vaswani2017.subnet.json
│   │   └── ...
│   └── technical/
│       ├── linux_kernel.subnet.json
│       └── ...
├── cross-subnet-links.jsonl          # All cross-subnet edges (separate for fast updates)
└── embeddings/
    ├── main_256d.index               # FAISS for main layer
    └── subnet_256d.index             # FAISS for subnet nodes (larger)
```

**Why sharded**: At 500K subnet nodes, a single JSON would be ~2GB. Sharding by
parent node means each file is 5-50KB, loads instantly, and can be updated independently.
The cross-subnet links file is separate because those edges span files.

**Lazy loading**: The GNN doesn't need all subnets in memory. Load subnet files
on demand when a pathfinding query enters that subnet. Cache recently-used subnets.

```python
class SubnetLoader:
    """Load subnet graphs on demand with LRU cache."""
    def __init__(self, subnet_dir, cache_size=500):
        self.subnet_dir = subnet_dir
        self.cache = LRUCache(maxsize=cache_size)

    def get_subnet(self, parent_id):
        if parent_id in self.cache:
            return self.cache[parent_id]

        # Map parent ID to file path
        domain = parent_id.split(':')[0].replace('wiki-', 'wikipedia/')
        path = f"{self.subnet_dir}/{domain}/{parent_id}.subnet.json"

        subnet = json.load(open(path))
        self.cache[parent_id] = subnet
        return subnet

    def preload_neighborhood(self, node_id, depth=2):
        """Preload subnets for nodes within depth hops on main layer."""
        neighbors = main_graph.neighbors(node_id, depth=depth)

            if n.has_subnet:
                self.get_subnet(n.id)  # warm cache
```

### Heterogeneous GNN (HeteroSAGE)

The flat GraphSAGE from v2 treats all edges the same. With two layers and 12+ edge
types, we need a **heterogeneous GNN** that learns different message-passing functions
for different edge types:

```python
import torch_geometric
from torch_geometric.nn import HeteroConv, SAGEConv

class HierarchicalGraphEncoder(nn.Module):
    """
    Heterogeneous GraphSAGE that handles main-layer and subnet nodes
    with different edge types and layer-aware message passing.
    """
    def __init__(self, in_dim=300, hidden=256, out_dim=256):
        super().__init__()

        # Different convolution for each edge type
        # Main layer edges
        main_conv = {
            ('main', 'shared_tags', 'main'): SAGEConv(in_dim, hidden),
            ('main', 'explicit_ref', 'main'): SAGEConv(in_dim, hidden),
            ('main', 'semantic', 'main'): SAGEConv(in_dim, hidden),
        }

        # Layer transition edges
        transition_conv = {
            ('main', 'dive', 'subnet'): SAGEConv(in_dim, hidden),
            ('subnet', 'surface', 'main'): SAGEConv(in_dim, hidden),
        }

        # Subnet edges
        subnet_conv = {
            ('subnet', 'citation', 'subnet'): SAGEConv(in_dim, hidden),
            ('subnet', 'section_link', 'subnet'): SAGEConv(in_dim, hidden),
            ('subnet', 'cross_subnet', 'subnet'): SAGEConv(in_dim, hidden),
        }

        all_conv = {**main_conv, **transition_conv, **subnet_conv}

        self.conv1 = HeteroConv(all_conv, aggr='mean')
        # Layer 2-4: same structure, different weights
        self.conv2 = HeteroConv(self._make_conv(hidden, hidden), aggr='mean')
        self.conv3 = HeteroConv(self._make_conv(hidden, hidden), aggr='mean')
        self.conv4 = HeteroConv(self._make_conv(hidden, out_dim), aggr='mean')

        self.norms = nn.ModuleDict({
            'main': nn.LayerNorm(hidden),
            'subnet': nn.LayerNorm(hidden),
        })

    def _make_conv(self, in_d, out_d):
        """Create convolution dict for all edge types."""
        edge_types = [
            ('main', 'shared_tags', 'main'),
            ('main', 'explicit_ref', 'main'),
            ('main', 'semantic', 'main'),
            ('main', 'dive', 'subnet'),
            ('subnet', 'surface', 'main'),
            ('subnet', 'citation', 'subnet'),
            ('subnet', 'section_link', 'subnet'),
            ('subnet', 'cross_subnet', 'subnet'),
        ]
        return {et: SAGEConv(in_d, out_d) for et in edge_types}

    def forward(self, x_dict, edge_index_dict):
        """
        x_dict: {'main': [N_main, in_dim], 'subnet': [N_subnet, in_dim]}
        edge_index_dict: {edge_type: [2, num_edges]}
        """
        for i, conv in enumerate([self.conv1, self.conv2, self.conv3]):
            x_dict = conv(x_dict, edge_index_dict)
            x_dict = {k: F.relu(self.norms[k](v)) for k, v in x_dict.items()}

        x_dict = self.conv4(x_dict, edge_index_dict)
        return x_dict
```

**Why HeteroConv**: A `shared_tags` edge between two main-layer nodes should carry
different information than a `citation` edge between two subnet nodes. HeteroConv
learns separate weight matrices for each edge type, so the model understands that
"citation link" and "tag overlap" encode different kinds of relationships.

### Hierarchical Pathfinder Head

The pathfinder needs to make a **three-way decision** at each step:
1. **Traverse** main layer (stay on same level)
2. **Dive** into a subnet (go deeper to find cross-links)
3. **Surface** back to main (return from subnet)

```python
class HierarchicalPathfinderHead(nn.Module):
    """
    Pathfinder that navigates the two-layer network.

    At each step, decides:
    1. Should I stay on the current layer or switch? (dive/surface/stay)
    2. Which neighbor should I move to?
    3. What's the estimated remaining cost?
    """
    def __init__(self, dim=256, num_strategies=8):
        super().__init__()
        self.strategy_embed = nn.Embedding(num_strategies, 64)

        # Layer decision: dive / surface / stay
        self.layer_decision = nn.Sequential(
            nn.Linear(dim * 2 + 64 + 4, 256),  # +4 for [current_depth, is_main, subnet_size, cross_links]
            nn.ReLU(),
            nn.Dropout(0.1),
            nn.Linear(256, 3),  # [stay, dive, surface]
        )

        # Next-hop scorer (within chosen layer)
        self.hop_scorer = nn.Sequential(
            nn.Linear(dim * 3 + 64, 512),
            nn.ReLU(),
            nn.Dropout(0.1),
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, 1),
        )

        # Cost estimator (accounts for exponential penalty)
        self.cost_estimator = nn.Sequential(
            nn.Linear(dim * 2 + 64 + 4, 256),
            nn.ReLU(),
            nn.Linear(256, 4),  # [est_main_hops, est_subnet_hops, est_total_cost, success_prob]
        )

    def forward(self, source, target, neighbors, strategy_id, context):
        """
        context: dict with current_depth, is_main, subnet_size, num_cross_links
        """
        strat = self.strategy_embed(strategy_id)
        ctx = torch.tensor([
            context['current_depth'] / 10,
            float(context['is_main']),
            context.get('subnet_size', 0) / 500,
            context.get('num_cross_links', 0) / 50,
        ])

        # Step 1: Decide layer action
        decision_input = torch.cat([source, target, strat, ctx])
        layer_probs = F.softmax(self.layer_decision(decision_input), dim=-1)
        # [stay_prob, dive_prob, surface_prob]

        # Step 2: Score neighbors (filtered by layer decision)
        scores = []
        for n_emb in neighbors:
            s = self.hop_scorer(torch.cat([source, n_emb, target, strat]))
            scores.append(s)

        # Step 3: Estimate remaining cost
        cost_est = self.cost_estimator(torch.cat([source, target, strat, ctx]))

        return {
            'layer_action': layer_probs,
            'neighbor_scores': torch.cat(scores),
            'cost_estimate': cost_est,
        }
```

**Training the depth intuition**: The model needs to learn WHEN diving is worthwhile.
Training signal comes from:
- Routes where diving found a cross-subnet shortcut (positive: dive was worth it)
- Routes where diving led to a dead end and surfacing was necessary (negative: dive was wasteful)
- The exponential cost model provides automatic supervision: routes with unnecessary
  deep subnet traversal have high cost, routes that surface early have low cost

### Training Data Generation for Subnets

The existing 599 route logs are all main-layer only. We need subnet traversal data:

```python
class HierarchicalRouteGenerator:
    """
    Generate synthetic training routes through the hierarchical network.
    Uses the cost model to create routes with known-optimal layer decisions.
    """
    def __init__(self, main_graph, subnet_loader, cost_model):
        self.main = main_graph
        self.subnets = subnet_loader
        self.cost = cost_model

    def generate_route(self, start, end, strategy='optimal'):
        """
        Generate a route from start to end, trying both:
        1. Main-only path (never dive)
        2. Paths that dive into subnets where cross-links exist

        Label the cheaper one as the "correct" route for training.
        """
        # Option A: Main-layer only
        main_path = dijkstra(self.main, start, end)
        main_cost = self.cost.path_cost(main_path)

        # Option B: Try diving at each node that has useful cross-links
        best_hybrid = main_path
        best_hybrid_cost = main_cost

        for i, node in enumerate(main_path):
            if not node.has_subnet:
                continue
            subnet = self.subnets.get_subnet(node.id)

            # Check if any subnet node has a cross-link that shortcuts
            for snode in subnet.nodes:
                for link in snode.cross_subnet_links:
                    target_parent = link.target_parent
                    if target_parent in main_path[i+1:]:
                        # Found a shortcut! Build hybrid path
                        hybrid = (
                            main_path[:i] +
                            [('dive', node.id, snode.id)] +
                            [('cross_subnet', snode.id, link.target)] +
                            [('surface', link.target, target_parent)] +
                            main_path[main_path.index(target_parent):]
                        )
                        hybrid_cost = self.cost.path_cost(hybrid)
                        if hybrid_cost < best_hybrid_cost:
                            best_hybrid = hybrid
                            best_hybrid_cost = hybrid_cost

        return {
            'route': best_hybrid,
            'cost': best_hybrid_cost,
            'main_only_cost': main_cost,
            'dive_worthwhile': best_hybrid_cost < main_cost,
            'savings': main_cost - best_hybrid_cost,
        }

    def generate_training_set(self, num_routes=10000):
        """Generate labeled training routes for the pathfinder."""
        routes = []
        for _ in range(num_routes):
            start = random.choice(self.main.nodes)
            end = random.choice(self.main.nodes)
            route = self.generate_route(start, end)
            routes.append(route)

            # Also generate depth-exploration routes to teach the model
            # when to STOP diving
            if route['dive_worthwhile']:
                # Generate a "too deep" variant where we go 1-2 hops
                # deeper than optimal — model should learn this is worse
                deep_route = self._extend_depth(route, extra_hops=2)
                deep_route['label'] = 'too_deep'
                routes.append(deep_route)

        return routes
```

### Cross-Subnet Link Discovery

The most valuable subnet feature is cross-links — when a citation in article A is
the same paper as a citation in article B, that's a strong implicit connection between
A and B that the main layer might not capture through tags alone.

```python
class CrossSubnetLinker:
    """
    Discover cross-subnet links by matching subnet nodes across parents.

    Types of matches:
    1. Exact citation match (same DOI, ISBN, or title)
    2. Entity match (same person, organization, concept)
    3. Semantic section similarity (similar content in different articles)
    """
    def __init__(self, text_encoder, similarity_threshold=0.85):
        self.encoder = text_encoder
        self.threshold = similarity_threshold

    def find_shared_citations(self, subnets):
        """
        Deduplicate citations across all subnets.
        Same paper cited in N articles → N*(N-1)/2 cross-links.
        """
        citation_index = {}  # normalized_title → [(parent_id, citation_node_id)]
        for parent_id, subnet in subnets.items():
            for node in subnet.citation_nodes:
                key = normalize_citation(node.title, node.doi)
                if key not in citation_index:
                    citation_index[key] = []
                citation_index[key].append((parent_id, node.id))

        cross_links = []
        for key, locations in citation_index.items():
            if len(locations) < 2:
                continue
            # All pairs of locations for this citation
            for i, (p1, n1) in enumerate(locations):
                for p2, n2 in locations[i+1:]:
                    cross_links.append({
                        'from': n1, 'to': n2,
                        'type': 'shared_citation',
                        'weight': 9,  # high weight: same paper is strong signal
                        'parent_from': p1,
                        'parent_to': p2,
                    })
        return cross_links

    def find_semantic_section_links(self, subnets, top_k=5):
        """
        Find sections in different articles that discuss the same topic.
        Uses the text encoder to compare section embeddings.
        """
        section_embeddings = []
        section_ids = []
        for parent_id, subnet in subnets.items():
            for node in subnet.section_nodes:
                emb = self.encoder.encode(node.text[:512])
                section_embeddings.append(emb)
                section_ids.append((parent_id, node.id))

        # Build FAISS index and find nearest neighbors
        index = faiss.IndexFlatIP(256)
        index.add(np.array(section_embeddings))

        cross_links = []
        for i, emb in enumerate(section_embeddings):
            distances, indices = index.search(emb.reshape(1, -1), top_k + 1)
            for dist, idx in zip(distances[0], indices[0]):
                if idx == i:
                    continue  # skip self
                if dist < self.threshold:
                    continue
                p1, n1 = section_ids[i]
                p2, n2 = section_ids[idx]
                if p1 == p2:
                    continue  # skip same-parent matches
                cross_links.append({
                    'from': n1, 'to': n2,
                    'type': 'section_similar',
                    'weight': int(dist * 10),  # cosine sim → weight
                    'parent_from': p1,
                    'parent_to': p2,
                })
        return cross_links
```

**Impact of cross-links on pathfinding**: A cross-subnet link creates an implicit
shortcut between two main-layer nodes. If wiki:Transformer has a citation to
"Attention Is All You Need" and wiki:BERT also cites it, the cross-link creates
a path: Transformer → (dive) → cite:vaswani → (cross) → cite:vaswani@BERT → (surface) → BERT.

The cost of this path: dive(0) + internal(2) + cross(6) + surface(0) = 8
vs. a main-layer path that might cost 12+ hops at weight 1-2 each.

The model learns when these subnet shortcuts are cheaper than main-layer traversal.

### Integration with Technical Documents

Technical documents (RFCs, manuals, API docs) follow the same subnet pattern but
with different internal structure:

```python
# RFC subnet builder
class RFCSubnetBuilder:
    def build(self, rfc_text, rfc_id):
        nodes = []
        edges = []

        # Sections become subnet nodes
        for section in parse_rfc_sections(rfc_text):
            nodes.append({
                'id': f'{rfc_id}/section:{section.number}',
                'type': 'section',
                'title': section.title,
                'text': section.text[:512],
            })

        # Normative references become citation nodes
        for ref in parse_rfc_references(rfc_text):
            nodes.append({
                'id': f'{rfc_id}/ref:{ref.tag}',
                'type': 'citation',
                'title': ref.title,
                'rfc_number': ref.rfc_number,
            })
            # Link from referring section to reference
            edges.append({
                'from': f'{rfc_id}/section:{ref.in_section}',
                'to': f'{rfc_id}/ref:{ref.tag}',
                'type': 'citation',
                'weight': 7,
            })

        # Sequential section links
        for i in range(len(nodes) - 1):
            if nodes[i]['type'] == 'section' and nodes[i+1]['type'] == 'section':
                edges.append({
                    'from': nodes[i]['id'],
                    'to': nodes[i+1]['id'],
                    'type': 'sequential',
                    'weight': 3,
                })

        return {'nodes': nodes, 'edges': edges}
```

**Cross-document subnet links**: RFC 793 (TCP) references RFC 791 (IP). Their subnets
link through shared normative references. A paper on "TCP congestion control" cites
RFC 793. Its subnet links to both the paper's subnet and the RFC's subnet through
shared citations. The hierarchical network naturally captures these relationships.

## Lessons Learned
- Hierarchical graphs require heterogeneous GNNs — homogeneous SAGEConv can't distinguish edge semantics
- Exponential depth penalty (base 2) naturally limits subnet depth to 2-3 useful hops
- Cross-subnet links are the highest-value edges in the entire network — they encode shared knowledge across documents
- Sharded subnet storage (one file per parent) scales better than monolithic graph files
- Lazy subnet loading with LRU cache keeps VRAM under control even with millions of subnet nodes
- Technical documents (RFCs, papers, manuals) map cleanly onto the same subnet model as Wikipedia

## Recommendations
- Build subnets BEFORE scaling to 1M main edges — the cross-subnet shortcuts reduce the number of main-layer edges needed
- Start with Wikipedia citation subnets (easiest to parse, highest cross-link density)
- Set exponential base to 2.0 initially; tune based on route log analysis (if agents never dive, lower the base; if they dive too deep, raise it)
- Pre-compute cross-subnet links as a batch job (GPU-accelerated FAISS matching), don't discover them at query time
- Keep subnet files small (<100KB each) — they need to load in <1ms for interactive pathfinding
- The HeteroSAGE upgrade from SAGEConv is a one-time architecture change — do it before Phase 2, not during scaling
