# Data Gathering Iteration 2: Parallel Hybrid Methods & Academic APIs

## Context
Iteration 1 established 5 data gathering methods but only 1 (web search) was fully functional. Team 1 researched improvements and recommended adding OpenAlex, Wikidata, parallel execution, credibility tiers, and TF-IDF deduplication.

## Method
Built 2 new methods (OpenAlex DG-0006, Wikidata DG-0007), rewrote the hybrid method with all recommended improvements, and created a deduplication utility and benchmark runner.

### Key Technical Decisions
- **OpenAlex abstract reconstruction**: OpenAlex stores abstracts as inverted indexes (`{word: [positions]}`). We reconstruct readable text by sorting positions and joining words.
- **Parallel execution**: `concurrent.futures.ThreadPoolExecutor(max_workers=5)` runs all 5 sources simultaneously. Total hybrid time is dominated by the slowest source, not the sum.
- **TF-IDF deduplication**: Custom implementation using only stdlib. Tokenization -> TF computation -> IDF across all documents -> cosine similarity. Threshold 0.65 works well empirically.
- **Credibility weighting**: `weighted_score = corroboration_score * credibility_weight`. Academic sources get 1.5x, encyclopedias 1.2x, structured knowledge 1.1x, web 1.0x.

## Result
- 5 of 7 methods functional (up from 1 of 4)
- Hybrid v2: 46 data points, quality score 92, 5.1s (vs 31 points, score 55, 5.8s in iteration 1)
- OpenAlex: fastest academic source at 0.5s, 15 results with citation metadata
- Total data points across all methods: 146 (vs 31 in iteration 1)

## Lessons Learned
1. **OpenAlex is the best free academic API**: No key, fast, rich metadata, 250M+ works. Superior to arXiv for breadth.
2. **Parallel execution is a massive win**: Despite adding 2 more sources to the hybrid, total time decreased 12% because sources run simultaneously.
3. **Wikidata may block requests**: Their API returns 403 from some network environments. Code should always handle this gracefully.
4. **TF-IDF works well for cross-source dedup**: Even a simple stdlib-only implementation effectively identifies duplicate findings across different sources.
5. **Credibility tiers add meaningful signal**: Academic-sourced findings genuinely tend to be more reliable; weighting them higher improves result ranking.

## Recommendations
1. **Always use OpenAlex for academic queries** — it's faster and broader than arXiv
2. **Use the hybrid v2 method as the default** — best quality score by far
3. **Consider adding Semantic Scholar** for citation graph traversal (complements OpenAlex)
4. **Add result caching** with configurable TTL to avoid redundant API calls
5. **Implement query expansion** with synonym generation for better recall
6. **Add CrossRef** for DOI resolution and metadata enrichment
