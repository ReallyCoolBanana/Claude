# Archive Tools for Knowledge Base System

## Context
The knowledge base system needed automated validation and maintenance tools. Prior work (KB-0001) identified that validation should be mandatory and cross-references are essential but were lacking formal checking. Three archive tools were built in parallel to address these gaps.

## Method
Three agents worked in parallel, each building one standalone Python script (stdlib-only, no external dependencies):

1. **kb_validator.py (SCR-0012)** — Validates KB entries and index.json consistency
2. **index_rebuilder.py (SCR-0013)** — Auto-rebuilds index.json from directory scans
3. **cross_ref_checker.py (SCR-0014)** — Validates all cross-references with cycle detection

Each tool parses YAML frontmatter from .md files using a custom stdlib parser and outputs structured results.

## Result
All 3 tools built and verified working:

- **kb_validator** found 1 real error (missing `multi-team` tag in tag_index for KB-0003) and 1 warning (extra `multi-agent` tag for KB-0003)
- **index_rebuilder** detected diffs in knowledge-base/index.json (builds_on fields missing from some entries) and successfully generates teams/sessions/index.json from scratch
- **cross_ref_checker** found 0 errors and 11 warnings (orphan scripts not registered in index.json, including the 3 newly created tools before registration)

## Lessons Learned
1. **YAML frontmatter parsing without PyYAML** is feasible for the simple key-value format used in this repo, but would break on nested structures or multi-line values.
2. **Tag index inconsistencies** are easy to introduce manually — the index_rebuilder can auto-fix these.
3. **Many orphan scripts exist** from previous stress-testing that were never registered in index.json.
4. **The builds_on field in index.json entries** was missing for some entries that had it in their frontmatter — the index and files were out of sync.

## Recommendations
1. Run `python3 storage/scripts/kb_validator.py` before committing KB changes.
2. Run `python3 storage/scripts/index_rebuilder.py --fix` to auto-repair index drift.
3. Run `python3 storage/scripts/cross_ref_checker.py` to detect broken references and cycles.
4. Register orphan scripts or delete them to keep the index clean.
5. Consider adding these tools to a pre-commit hook or CI pipeline.
