# Data Gathering Methods: Continuous Improvement Loop

## Context
Built and iteratively improved a suite of data gathering methods using a 3-team continuous improvement loop (Research → Software → Verification → loop).

## Method
3-team loop architecture:
- **Team 1 (Research)**: 2 leads + 8 sub-agents researched best practices and new data sources
- **Team 2 (Verification/Storage)**: 1 lead + 4 sub-agents verified, stored, analyzed, and generated feedback
- **Team 3 (Software)**: 1 lead + 4 sub-agents built and improved methods across 2 iterations

## Result: 7 Data Gathering Methods

| ID | Method | Speed | Data Points | Quality | Best For |
|----|--------|-------|-------------|---------|----------|
| DG-0001 | WebSearch (DuckDuckGo) | 3.2s | 10 | 60 | General web info |
| DG-0002 | Wikipedia API | 2.9s | 5 | 40 | Encyclopedic overviews |
| DG-0003 | arXiv API | 1.5s | 10 | 68 | Academic papers |
| DG-0004 | **Hybrid v2** | **5.5s** | **71** | **100** | **Comprehensive research** |
| DG-0005 | Iterative Deepening | 9.4s | 30 | 82 | Exploratory deep dives |
| DG-0006 | OpenAlex | 1.4s | 15 | 72 | Academic breadth |
| DG-0007 | Wikidata SPARQL | 1.4s | 10 | 64 | Structured knowledge |

### Key Free APIs (No Key Required)
1. **OpenAlex** `api.openalex.org` — 250M+ academic works
2. **Wikidata** `query.wikidata.org/sparql` — Structured world knowledge
3. **CrossRef** `api.crossref.org` — 150M+ citation records
4. **arXiv** `export.arxiv.org/api` — Physics/CS/Math papers
5. **DuckDuckGo HTML** `html.duckduckgo.com/html` — Web search
6. **Wikipedia** `en.wikipedia.org/w/api.php` — Encyclopedia

### Improvement Loop Results (Iteration 1 → 2)
- Quality score: 88 → **100** (+14%)
- Max data points: 30 → **71** (+137%)
- Methods: 5 → **7** (+40%)
- Hybrid speed: 7.8s → **5.5s** (-29%, via parallel execution)

## Lessons Learned
1. **Parallel execution is the single biggest speed win** — ThreadPoolExecutor across 5 sources cut hybrid time 29%
2. **Cross-source corroboration scoring matters** — findings confirmed by multiple sources are reliably higher quality
3. **Source credibility tiers improve ranking** — academic > government > news > blog
4. **The improvement loop works** — Team 2's feedback directly drove Team 3's iteration 2 improvements
5. **More sub-agents per research lead doesn't scale linearly** — 4 is the sweet spot per lead

## Recommendations
1. Use **Hybrid v2** (DG-0004) as the default method for any research task
2. Use **OpenAlex** (DG-0006) when speed matters and academic sources suffice
3. Use **Iterative** (DG-0005) for exploratory topics where you don't know what to search for
4. Run `benchmark_runner.py` to compare methods for your specific use case
5. Future iterations should add: Semantic Scholar, SEC EDGAR, RSS aggregation
