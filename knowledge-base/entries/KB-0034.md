# Vulkan CMake Build Patterns: FetchContent, Shaders, and Distribution

## Context
Research into CMake build patterns for Vulkan projects: FetchContent dependency management, shader compilation automation, Windows-specific quirks, release distribution, and SPIR-V embedding techniques.

## Method
Web research across CMake documentation, GitHub repos, Vulkan SDK docs, and community guides. Focused on patterns that enable clone-and-build workflows on Windows.

## Result

### 1. FetchContent Dependency Management

**Confirmed working versions (early 2026):**
| Library | Tag | CMake Target |
|---------|-----|-------------|
| GLFW | `3.4` | `glfw` |
| GLM | `1.0.1` | `glm::glm` (since 1.0; older used `glm`) |
| VMA | `v3.2.0` | `GPUOpen::VulkanMemoryAllocator` |
| vk-bootstrap | `v1.4.334` | `vk-bootstrap::vk-bootstrap` |

**Key practices:**
- Set `GLFW_BUILD_EXAMPLES/TESTS/DOCS OFF` **before** `FetchContent_MakeAvailable`
- Use `GIT_SHALLOW TRUE` to avoid downloading full git history
- VMA requires `#define VMA_IMPLEMENTATION` in exactly one .cpp file
- GLM commit hash preferred over tag for security/reproducibility

### 2. Shader Compilation in CMake

**Best pattern** — `add_custom_command` with `DEPENDS` (only recompiles changed shaders):
```cmake
find_package(Vulkan REQUIRED COMPONENTS glslc)
foreach(SHADER_SOURCE ${SHADER_FILES})
    get_filename_component(SHADER_NAME ${SHADER_SOURCE} NAME)
    set(SPIRV_OUTPUT "${CMAKE_CURRENT_BINARY_DIR}/shaders/${SHADER_NAME}.spv")
    add_custom_command(
        OUTPUT ${SPIRV_OUTPUT}
        COMMAND Vulkan::glslc ${SHADER_SOURCE} -o ${SPIRV_OUTPUT}
        DEPENDS ${SHADER_SOURCE}
    )
    list(APPEND SPIRV_FILES ${SPIRV_OUTPUT})
endforeach()
add_custom_target(Shaders DEPENDS ${SPIRV_FILES})
```

**Alternative:** `cmake-spirv` reusable module (fetchable via FetchContent)

### 3. Windows-Specific Build Quirks

- `FindVulkan.cmake` uses `VULKAN_SDK` env var (set by LunarG installer)
- Must open new terminal after SDK install for env var visibility
- Console vs Windows subsystem: `add_executable(app main.cpp)` = console; `add_executable(app WIN32 main.cpp)` = no console
- Toggle per-config: `WIN32_EXECUTABLE $<NOT:$<CONFIG:Debug>>`
- Available CMake targets (3.24+): `Vulkan::glslc`, `Vulkan::glslangValidator`, `Vulkan::shaderc_combined`, `Vulkan::volk`, `Vulkan::dxc_exe`
- glslang CMake config in Windows SDK sometimes broken; build from source or use vcpkg if needed

### 4. Release Distribution (Clone-and-Build)

Only prerequisite: Vulkan SDK installed. Everything else via FetchContent.
```
cmake -B build -S .
cmake --build build --config Release
```

**Key practices:**
- Set `CMAKE_RUNTIME_OUTPUT_DIRECTORY` to place exe and shaders together
- Post-build copy shaders to output directory:
```cmake
add_custom_command(TARGET ${PROJECT_NAME} POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_directory
        "${CMAKE_CURRENT_BINARY_DIR}/shaders"
        "$<TARGET_FILE_DIR:${PROJECT_NAME}>/shaders"
)
```

### 5. SPIR-V Embedding Techniques

| Technique | Platform | Alignment | Notes |
|-----------|----------|-----------|-------|
| `xxd -i` | Unix/Git Bash | uint8_t | Needs alignment cast for Vulkan |
| `vksbc` | Cross-platform | uint32_t | Correct for `vkCreateShaderModule` |
| CMake `file(READ)` | Cross-platform | Custom | Pure CMake, no external tools |
| `incbin` | Cross-platform | Binary | Zero-copy assembly embedding |
| CMRC | Cross-platform | API | Full resource compiler |
| C++23 `#embed` | Compiler-dependent | Native | Not yet practical (2026) |

**Recommendation:** Use file loading during development, embedding for final distribution.

## Lessons Learned

1. **`add_custom_command` with DEPENDS is superior** to `add_custom_target` alone — only recompiles changed shaders
2. **VMA_IMPLEMENTATION must be in exactly one .cpp** — common source of linker errors
3. **New terminal required after Vulkan SDK install on Windows** — common CI gotcha
4. **Post-build shader copy is essential** for the exe to find shaders at runtime
5. **Library versions matter**: GLM 1.0+ changed target from `glm` to `glm::glm`

## Recommendations

1. Use FetchContent with `GIT_SHALLOW TRUE` for all dependencies except Vulkan SDK
2. Use `Vulkan::glslc` imported target (CMake 3.19+) instead of `find_program(glslc)`
3. Add post-build copy command for shader .spv files
4. Update to latest library versions: VMA v3.2.0, vk-bootstrap v1.4.334
5. For distribution, provide CMakePresets.json for convenient configuration
