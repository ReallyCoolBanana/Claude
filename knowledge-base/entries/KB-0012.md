# Free Public APIs for Government and Open Data (TEAM-0011 Catalog)

## Context
Needed to identify the best free public APIs for government and open data that an AI system can use programmatically. Focus areas: US government data, international data, weather/climate, and geospatial data.

## Method
Systematic web search across each category, verifying base URLs, documentation links, authentication requirements, rate limits, and response formats for each API. Only included APIs with verified, working endpoints.

## Result
Identified and cataloged 7 high-quality free public APIs:

1. **FRED API** (SRC-0018) - 820K+ economic time series, API key required, 120 req/min
2. **US Census Bureau API** (SRC-0019) - 1,600+ endpoints, demographics/economic, API key optional
3. **BLS Public Data API** (SRC-0020) - Labor/employment data, no key needed for v1, 25-500 queries/day
4. **NWS Weather API** (SRC-0021) - US weather forecasts/alerts, completely free, no key
5. **Open-Meteo API** (SRC-0022) - Global weather, no key, 10K calls/day, sub-10ms latency
6. **World Bank Indicators API** (SRC-0023) - 16K indicators across 200+ countries, no auth
7. **US Treasury Fiscal Data API** (SRC-0024) - 80 endpoints, federal financial data, no auth

All return JSON. Five require no authentication at all. Two require free API keys (instant registration).

## Lessons Learned
- US government APIs are remarkably accessible: most require no authentication
- Rate limits vary dramatically: BLS v1 allows only 25 queries/day while FRED allows 120/minute
- NWS API is the only truly zero-barrier weather API for US data; Open-Meteo fills the global gap
- World Bank API is the single best source for international comparative data
- Treasury Fiscal Data API is underappreciated: 80 endpoints, no auth, supports CSV/JSON/XML
- For AI usage, the most important factors are: consistent JSON schemas, pagination support, and searchable metadata

## Recommendations
- For economic data: Start with FRED (broadest coverage, fast, well-structured)
- For demographic/geographic: Census API + TIGERweb for boundaries
- For weather: NWS for US, Open-Meteo for global
- For international comparisons: World Bank Indicators API
- For federal finances: Treasury Fiscal Data (simplest to use, no auth)
- Always register for free API keys where available -- rate limits are significantly higher
- BLS v1 is a bottleneck at 25 queries/day; always use v2 with a free key for serious work
