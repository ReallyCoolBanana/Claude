# Vulkan Initialization Code Patterns: vk-bootstrap + VMA Reference

## Context
Detailed code patterns for Vulkan initialization using vk-bootstrap and VMA, covering instance creation, device selection, swapchain, command buffers, synchronization, and cleanup order. Based on vk-bootstrap examples, vkguide.dev, and vulkan-tutorial.com.

## Method
Analysis of vk-bootstrap triangle.cpp, vkguide.dev chapters 1-3, Vulkan Tutorial frames-in-flight, VMA Quick Start, and KDAB synchronization guide. 15+ sources.

## Result

### 1. Instance Creation
- `use_default_debug_messenger()` auto-sets up VK_EXT_debug_utils
- `request_validation_layers()` enables VK_LAYER_KHRONOS_validation (pass false for release)
- `require_api_version(1, 3, 0)` sets minimum Vulkan version
- vk-bootstrap auto-enables windowing extensions

### 2. Physical Device Selection
- `set_surface()` required for presentation support check
- `set_required_features_13()` / `set_required_features_12()` reject GPUs lacking features
- Features set during selection **auto-propagate** to DeviceBuilder — specify once only
- `detailed_failure_reasons()` gives per-GPU rejection explanations
- Discrete GPU preferred by default (ranked selection)

### 3. Logical Device Creation
- `DeviceBuilder{physical_device}` — must use `vkb::PhysicalDevice`, not raw `VkPhysicalDevice`
- All features/extensions from selector automatically enabled
- `get_queue(vkb::QueueType::graphics/present/compute/transfer)` retrieves queues
- `get_queue_index()` retrieves family index for command pool creation

### 4. VMA Allocator Setup
- `VMA_IMPLEMENTATION` in exactly ONE .cpp file
- Created AFTER VkDevice, destroyed BEFORE VkDevice
- `vulkanApiVersion` must match instance version (0 = Vulkan 1.0)
- `VMA_ALLOCATOR_CREATE_BUFFER_DEVICE_ADDRESS_BIT` if using BDA
- If using volk: supply `vkGetInstanceProcAddr`/`vkGetDeviceProcAddr` via `VmaVulkanFunctions`

### 5. Swapchain Creation
- `VK_FORMAT_B8G8R8A8_SRGB` for gamma-correct, `VK_FORMAT_B8G8R8A8_UNORM` for manual gamma
- Default present mode: MAILBOX with FIFO fallback; FIFO guaranteed by spec
- `add_image_usage_flags(VK_IMAGE_USAGE_TRANSFER_DST_BIT)` enables blit/clear to swapchain
- `set_old_swapchain()` enables efficient recreation on resize
- `get_images()` and `get_image_views()` return managed resources

### 6. Command Pool/Buffers (Per-Frame)
- **One command pool per frame in flight** — avoids contention
- `VK_COMMAND_POOL_CREATE_RESET_COMMAND_BUFFER_BIT` for individual buffer reset
- Alternative: skip flag, use `vkResetCommandPool()` for bulk reset (slightly more efficient)

### 7. Sync Objects and Draw Loop
- Fences **must** be created `VK_FENCE_CREATE_SIGNALED_BIT` or first wait deadlocks
- Per-frame: 1 fence (CPU-GPU), 2 semaphores (swapchain + render, GPU-GPU)
- Draw cycle: Wait fence → Acquire image → Reset+Record cmd → Submit → Present → Advance frame
- `VkSubmitInfo2` (Vulkan 1.3/sync2) replaces `VkSubmitInfo` with per-semaphore stage masks

### 8. Cleanup / Destruction Order
**Rule: destroy in REVERSE order of creation.**
1. `vkDeviceWaitIdle()` — ensure no GPU work in flight
2. Per-frame objects (command pools, fences, semaphores)
3. Pipelines, pipeline layouts, render passes
4. Framebuffers
5. Swapchain image views, then swapchain
6. All VMA allocations, then `vmaDestroyAllocator` (BEFORE device)
7. `vkDestroyDevice`
8. `vkDestroySurfaceKHR` (needs instance)
9. Debug messenger
10. `vkDestroyInstance` (last Vulkan object)
11. Window destroy

**Validation errors if violated:**
- `VUID-vkDestroyDevice-device-05137`: child objects not destroyed before device
- `VUID-vkDestroyInstance-instance-00629`: child objects not destroyed before instance

## Lessons Learned

1. **DeviceBuilder must receive `vkb::PhysicalDevice`, not raw `VkPhysicalDevice`** — the vkb object carries feature/extension info that auto-propagates
2. **Fences must start signaled** — otherwise first frame deadlocks on `vkWaitForFences`
3. **VMA_IMPLEMENTATION in exactly one .cpp** — common linker error source
4. **Cleanup order matters** — validation layers catch ordering violations
5. **`set_old_swapchain()` for efficient resize** — vk-bootstrap handles the handoff

## Recommendations

1. Store `vkb::PhysicalDevice` (not just `VkPhysicalDevice`) for use with `DeviceBuilder`
2. Use per-frame command pools for multi-buffered rendering
3. Always pass `VK_FENCE_CREATE_SIGNALED_BIT` to fence creation
4. Match `VmaAllocatorCreateInfo.vulkanApiVersion` to instance API version
5. Use `vkb::destroy_*` helpers for clean shutdown when using vk-bootstrap
