# Analysis Methods Index

This directory contains guides and templates for each stock-picking method tracked by the market research system. Each guide defines the method, lists key metrics and signals, and provides a structured approach for applying it.

## Methods

### 1. [Fundamental Analysis](fundamental.md)
Evaluate a company's intrinsic value using financial statements, valuation ratios, growth metrics, and qualitative factors like competitive moats and management quality. Best for medium- to long-term investment theses.

### 2. [Technical Analysis](technical.md)
Analyze price action and volume data to identify trends, reversals, and entry/exit points. Uses indicators like moving averages, RSI, MACD, and chart patterns. Best for timing entries and short- to medium-term trades.

### 3. [Sentiment Analysis](sentiment.md)
Gauge market mood through news sentiment, social media activity, insider trading signals, and analyst rating changes. Useful as a contrarian indicator or for identifying catalysts before they are priced in.

### 4. [Quantitative Methods](quantitative.md)
Apply statistical and mathematical models to identify mispricings, factor exposures, and systematic trading opportunities. Includes factor models, statistical arbitrage, and mean reversion strategies.

### 5. Macro / Sector Analysis
Assess the broader economic environment, sector rotation dynamics, interest rate impacts, and geopolitical risks. Provides the top-down context that frames individual stock picks. *(Guide to be added by a future team.)*

## Combining Methods

The strongest picks typically combine multiple methods. For example:
- Fundamental analysis identifies an undervalued company.
- Technical analysis pinpoints a good entry point.
- Sentiment analysis confirms the market hasn't yet caught on.
- Quantitative methods validate the statistical edge.
- Macro analysis confirms the sector tailwind.

When logging a pick, note the primary method but reference supporting analyses from other methods.
