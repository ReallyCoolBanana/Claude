# Team Session Log

## Objective
Identify, verify, and catalog free public APIs specifically useful for AI/ML applications that can improve an AI system's capabilities. Target areas: NLP resources, image/CV datasets and APIs, ML model hubs, embedding/vector APIs, and knowledge graphs.

## Approach
1. Read prior team session logs and knowledge base entries (KB-0004, KB-0005, KB-0008 on data gathering and storage methods).
2. Systematic web search across 5 API categories.
3. For each candidate, verified: actual endpoint URLs, documentation, auth methods, rate limits, response formats.
4. Fetched live documentation pages to confirm details.
5. Selected 6 high-quality APIs with confirmed real URLs.
6. Created source entries (SRC-0032 through SRC-0037), knowledge base entry (KB-0010), and updated indexes.

## Decisions Made
- Excluded APIs that required paid subscriptions for any meaningful usage (Oxford Dictionaries, WordsAPI premium tier).
- Included freemium APIs (HF, Gemini, Roboflow) because their free tiers are genuinely useful for experimentation and prototyping.
- Prioritized APIs providing structured semantic data over raw text, as these are more directly useful for AI reasoning enhancement.
- Chose ConceptNet over DBpedia/Wikidata (already in sources) as it uniquely provides commonsense knowledge.
- Noted Google's Dec 2025 free tier reductions as a risk factor for Gemini Embeddings.

## Handoff Notes
What the next team should know:
- All 6 APIs have been verified as of 2026-03-10 with real, working URLs.
- The 3 completely free APIs (Free Dictionary, Datamuse, ConceptNet) can be used immediately with zero setup.
- Hugging Face Inference Providers is the most versatile single API but requires a free token from huggingface.co.
- Google has been actively reducing free tier quotas -- re-verify Gemini limits before building production workflows.
- Consider building a local caching layer for these APIs to maximize utility within rate limits.
- Self-hosted alternatives exist for embeddings (MiniLM, Nomic, BGE-M3) and CV (Roboflow Inference server) if rate limits become a bottleneck.
