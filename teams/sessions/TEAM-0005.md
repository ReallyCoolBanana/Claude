# Team 3 (Software) — Iteration 2 Session Log

## Objective
Implement iteration 2 improvements to the data gathering system based on Team 1A and 1B research recommendations. Build 2 new methods, improve the hybrid method, add deduplication, and run benchmarks.

## Approach
1. Read all existing methods and iteration 1 benchmark data
2. Built OpenAlex method (DG-0006) — free academic API with 250M+ works
3. Built Wikidata method (DG-0007) — structured knowledge extraction
4. Created TF-IDF deduplication utility (dedup_utils.py)
5. Rewrote hybrid method v2 with parallel execution, 5 sources, credibility tiers, corroboration scoring
6. Created benchmark_runner.py for standardized benchmarking
7. Ran full iteration 2 benchmarks

## Decisions Made
- **OpenAlex over Semantic Scholar**: OpenAlex was chosen as the primary new academic source because it's completely free, no API key needed, and covers 250M+ works. Abstract reconstruction from inverted index format was implemented.
- **Wikidata via REST API**: Used Wikidata's `wbsearchentities` and `wbgetentities` API endpoints rather than SPARQL to keep the implementation simpler and more reliable.
- **Parallel execution**: Used `concurrent.futures.ThreadPoolExecutor` with 5 workers in the hybrid method to run all sources simultaneously, reducing total time.
- **Credibility tiers**: academic (1.5x) > encyclopedia (1.2x) > structured_knowledge (1.1x) > web (1.0x). Weights applied to corroboration scores.
- **Deduplication threshold**: Set at 0.65 cosine similarity — balances avoiding false positives while catching genuine duplicates.
