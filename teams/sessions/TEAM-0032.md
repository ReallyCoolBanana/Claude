## Decisions Made
1. **Research before execution** — 7 research agents produced structured JSON reports, enabling well-informed execution
2. **Solo agent for MCP server** — lowest complexity, KB-0035 shows solo agents are 5-10x more efficient
3. **Scope to 4 TOCTOU bugs** — 2 Critical + 2 High, not all 22 found
4. **all-MiniLM-L6-v2** for embeddings — 384 dims, sufficient for ~40 docs, free/local
5. **stdio transport** for MCP — simplest, Claude Code default
6. **Project-scoped .mcp.json** — version-controlled, available to all repo users
