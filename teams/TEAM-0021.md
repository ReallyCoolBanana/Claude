## Decisions Made
- Authorization checks use PermissionError for consistency across modules
- Input validation uses ValueError with descriptive messages
- Cycle detection uses Kahn's topological sort (already referenced in codebase comments)
- Atomic JSONL writes use PIPE_BUF (4096) threshold with lock fallback for large messages
- Read offsets now persisted to SQLite read_offsets table (was in-memory only)
- Zombie work reclamation uses configurable timeout (default 1800s)
- Database indexes added for all high-traffic query patterns
